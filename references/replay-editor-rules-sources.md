## 已识别的差异与限制

| 项目 | 来源／实现差别 | 本技能的处理 |
|---|---|---|
| 修罗无人和牌的荒牌罚符 | 公开说明与本地专题口径不同；用户确认无人和牌、两听两未时每位未听付1500 | 正文采用用户确认的1500点口径；仍标记为用户确认而非维护助手服务器实测 |
| 自定义不听罚符 | 本地按每位未听者付款解释；生成实现对未指定三听参数的回退值与文档默认不一致 | 要求给出金额与人数，不据生成实现改动段位基线 |
| 宝牌开关联动 | 本地关闭杠表会限制杠里数量；关闭表宝会连带关闭里宝 | 四种选项概念分开，另报告本地联动，不当成通用官方规则 |
| 幻境风纪卡 | 用户确认不改变立直条件，只限制庄家能否和牌；生成判役分支存在相反条件 | 正文采用用户确认口径；生成实现不能作为验证依据 |
| 占星最后三张 | 公开说明禁止再开杠，本地专题提示编辑器未强制限制 | 采用公开规则的行动限制 |
| 万象百搭最优选择 | 官方说明选择时不计里宝；番数和符数相同的候选由用户确认随机选择 | 正文采用用户确认的同分随机口径；本地编辑器的编码顺序仅保留为实现差异 |
| 国标补花人和 | 雀渣排除首摸花牌后补花自摸的人和；本地仍可能显示人和 | 保留已知不一致，不以回放判役证明平台成立 |
| 国标番种版本 | 当前平台多出两种连环番，本地仍为旧目录及扩展 | 各自标版本，不宣称完全一致 |
| 下克上多人荣和 | 用户确认每位和牌家按其和牌时的点数分别计算倍率 | 正文采用逐家结算口径；仍未进行维护助手的服务器对局复核 |
| 下克上专题标题 | 本地文件首行误写“宝牌狂热”，内容与模式53、说明25101014对应下克上 | 按内容及公开ID归类 |

新增可选规则的公开说明、本地实现核对与离线检查不扩大 [段位基线已完成的验证](pending-verification.md)。本次没有执行活动／国标服务器对局验证，也没有修改来源仓库。
