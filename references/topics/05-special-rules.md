# 5. 特殊规则与限定

> 本章维护宝牌和包牌规则；采用口径的证据见 [规则索引](../rules-sources.md)。宝牌永远不是役；即使宝牌很多，手牌仍须另有至少一个役。

<a id="dora"></a>
## 5.1 宝牌指示牌与表宝牌

- 每局开局翻开一张表宝牌指示牌；其**下一张**牌才是表宝牌。
- 每次杠成立可增加一张表宝牌指示牌，最多五张；不同杠类型的翻牌时点见 [杠时序](09-call-kan-rules.md#kan-timing)。
- 指示牌的循环：数牌`1→2→…→9→1`；风牌`东→南→西→北→东`；三元牌`白→发→中→白`。红五按普通五处理，因此红五指示的宝牌为六。
- 一张手牌若同时对应多张指示牌，可重复计宝牌番。杠宝牌的翻开时序与岭上、抢杠见 [鸣牌与杠](09-call-kan-rules.md)。

## 5.2 里宝牌与赤宝牌

- **里宝牌**：仅立直和牌时翻开。每张已翻开的表宝牌指示牌，对应翻开一张里宝牌指示牌；计算方法与表宝相同。
- **赤宝牌**：四麻段位场使用红5万、红5筒、红5索各一张。红五在组面、对子、顺子和刻子判定中与同花色普通五相同，和牌时每张额外+1番。
- 三人麻将的拔北、北拔宝牌与相关平台设定见 [三人麻将规则差异](13-sanma.md)；它们不属于本章默认四麻规则。

<a id="pao"></a>
## 5.3 包牌

- 本节默认讨论雀魂段位场的大三元与大四喜责任支付；可选四杠子包牌与包杠见 [房规专题](15-room-options.md#155-责任支付与包杠)，不加入段位默认。
- 某家通过最后一次**碰或大明杠**帮助和牌者完成大三元或大四喜时，取得该副露的舍牌者成为责任者；暗杠不触发包牌。
- 包牌役满与非包牌役满分开计算，再合并各家收支。包牌只转移大三元或大四喜对应的役满部分；其他不支持责任支付、或与责任者无关的役满部分仍按通常规则结算。例如大三元复合字一色，责任者只承担大三元部分，字一色按常规自摸／荣和结算。
- 包牌自摸时，责任者独自支付包牌役满部分。
- 包牌荣和时，责任者与放铳者各支付包牌役满部分的一半；放铳者另支付全部非包牌部分。
- 责任者同时为放铳者时，两份包牌支付合并到同一人，该人另付全部非包牌部分。多倍包牌役满按实际倍数计算责任部分，不因包牌变回单倍；例如大四喜双倍复合字一色，分别计算两倍包牌与一倍普通役满。
- 三麻段位场沿用上述范围与触发规则；自摸包牌金额先去掉不存在的北家支付，再由责任者独自承担实际总额。荣和包牌不扣自摸损，仍按正常荣和点数分摊，具体见 [三麻计分](13-sanma.md)。

### 包牌的本场划分

本场单独计算一次，不按役满种类或倍数重复收取；每本总额仍为`(玩家数-1)*100`。单家和牌按下表分配，多家荣和仍沿用 [本场与供托规则](04-scoring.md#honba-deposits)。

| 和牌情况 | 本场付款者 |
|---|---|
| 荣和，有包牌或无包牌，责任者与放铳者相同或不同 | 放铳者支付全部本场 |
| 自摸，全部打点均为同一责任者的包牌部分 | 责任者支付全部本场 |
| 自摸，包牌役满复合非包牌役满 | 每名实际其他玩家每本各付100点，责任者也正常参与 |
| 自摸，无包牌 | 每名实际其他玩家每本各付100点 |

三麻按实际两名对手计算，每本共200点；本场不按包牌与非包牌打点的比例拆分。供托依和牌者归属规则独立加入，不由责任者重复支付。上述本场口径取自用户指定的本地资料，来源与房规范围见 [2026-10-09包牌确认记录](../evidence/pao-confirmations-2026-10-09.md)，逐人金额见 [复杂包牌实例](../examples/scoring.md#complex-pao)。

## 5.4 不作为默认规则的设定

- **头跳**：多人同时荣和时，仅距离放铳者最近的玩家和牌。雀魂段位场文档不把它当默认规则。
- **切上满贯**：将4番30符、3番60符直接上调满贯。段位场文档默认不采用。
- **无赤牌、封闭断幺九、不同役满复合方式**：均可能出现在比赛房或其他平台，必须明确标注后才可使用。
