# 8. 雀魂段位场赛制与终局

> 本章说明四人麻将段位场的赛制层规则。具体房间的原点、返点、延长与段位分仍应以客户端当期显示为准；规则差异的维护入口为 [规则基线](../rules-sources.md)。

## 8.1 对局类型与初始点数

- 段位场常见对局类型为**东风战**与**半庄战**；东风战以东场为基础，半庄战以东场、南场为基础。
- 四麻段位场原点25000、返点30000；返点为原点加5000。三麻原点35000、返点40000，见 [三麻规则](13-sanma.md)。
- 东风战常规最后局为东4、半庄战为南4；常规最后局流庄后无人达到30000且无飞人时，分别南入／西入。完整终局判断见8.4。
- 段位分按最终顺位与当前段位场规则结算，不等同于牌局内持有点数。牌局内点数只用于决定该场排名与飞人。

## 8.2 局数推进与连庄

- 局号从东1局开始。连庄、流庄和本场变化的共通规则由 [游戏流程](02-game-flow.md) 维护；本章只负责结算后的终局判断。
- 本场的具体支付见 [计分](04-scoring.md)。

## 8.3 飞人与提前结束

- 任一玩家点数降至0点以下即发生飞人(不含0点本身)，该局结算后整场立即结束。
- 飞人优先于继续进行下一局或延长；出现飞人后牌局立即结束, 最终排名按该局结算后的点数确定。
- 立直棒已支付即留在供托；飞人终局时，若有和牌则按和牌分配，若无人和牌则全部供托归结算顺位为1的玩家。

## 8.4 终局、延长与西入

- 先完成小局点数结算，再检查是否终局；检查通过后才执行连庄／轮庄与局数推进。
- 下列算法适用于**四人东、四人南及三麻东／南段位场**，已由用户逐项确认边界条件并报告完成实际验证；三麻参数同时见 [三麻赛制](13-sanma.md)。公开配置只确认原点／返点，不能单独证明完整终局裁定。

### 共通终局判断（用户确认）

每个小局结算后检查，飞人适用于整场；其余条件从常规最后局开始检查，包括该局的连庄局和延长场各局。`True`表示继续，`False`表示终局。点数与顺位均取本局结算后的值；“庄家”指刚结束小局的庄家，检查在轮庄前执行。“流庄”指本局结束后庄家不再连庄。恰好等于返点也视为达到；0点本身不构成负点飞人。

| 玩法 | 常规最后局 | 延长最后局（流庄即终局） | 返点 |
|---|---|---|---|
| 四人东 | 东4 | 南4 | 30000 |
| 四人南 | 南4 | 西4 | 30000 |
| 三麻东 | 东3 | 南3 | 40000 |
| 三麻南 | 南3 | 西3 | 40000 |

伪代码中小局用`(场序, 局号)`表示，东、南、西场的场序依次为1、2、3，例如南4为`(2, 4)`；`点数`为本局结算后的各家点数列表，`庄家`为当局庄家的列表下标。根据上表传入对应参数：

```python
def judge(当局, 常规最后局, 延长最后局, 返点, 点数, 庄家, 庄家顺位, 流庄):
    if min(点数) < 0:
        return False
    if 当局 < 常规最后局:
        return True
    if 庄家顺位 == 1 and 点数[庄家] >= 返点:
        return False
    if 当局 == 常规最后局 and 流庄 and max(点数) >= 返点:
        return False
    if 当局 == 延长最后局 and 流庄:
        return False
    return True
```

- 常规最后局流庄时，有人达到返点则终局；所有人均不足返点且无人负点，则进入延长场第1局。庄家未达到返点或不是第一名时，即使发生流庄，也仍按本条件判断。
- 延长场中，非庄家达到返点不独立触发终局；仍按负点飞人、庄家第一且达到返点、延长最后局流庄判断。
- 延长最后局未流庄且其余终局条件不成立，可继续该局连庄；流庄则直接终局，不再进入下一场。四人东的南4流庄、三麻东的南3流庄与三麻南的西3流庄均如此。
- 0点本身不会飞人；只有结算后出现负点才立即终局。

以四人南为例：

- 南4流庄时，若有人达到30000则终局；所有人均不足30000且无人负点，则进入西1局。
- 南4未流庄时，即使有闲家达到30000，也继续南4连庄；庄家第一且达到30000则终局。
- 西场中，非庄家达到30000**不独立触发终局**；仍检查负点飞人、庄家第一且达到返点、西4流庄三项条件，不能加入“西场有人达到返点即结束”的分支。
- 西4未流庄且其余终局条件不成立，继续西4连庄；西4流庄则终局，不进入北场。

## 8.5 排名、同点与立直棒

- 对局结束后按最终点数从高到低确定一至四位；精确同点时，按整场刚开局时的东、南、西、北顺序排名，东优先、北最后。起家座次整场固定，不随轮庄或进入南／西场改变。点数不同仍以点数为先。
- 段位场允许多人荣和；四麻一炮三响时三家分别结算和牌，不作途中流局。和牌资格不按头跳筛成一家。
- 多家荣和的本场和供托由 [计分规则](04-scoring.md#honba-deposits) 分配；和牌收支全部完成后再用于本章的终局及排名判断。
- 无人和牌终局时，全部供托归结算顺位为1的玩家。先按结算点数及固定起家顺序确定第一名，再将供托全部计入该玩家点数；供托只加给原有第一名，不参与重排，因此加入前后的原有顺位不变。
- 目标不是单局最大得点，而是最终顺位；All Last 时应同时考虑点差、亲番、本场、供托和是否会飞人。

## 8.6 段位分阅读要点

- 段位分取决于段位、对局类型、最终顺位和平台结算表，不能仅按“赢了多少点”推导。
- 同一顺位在不同段位场的增减幅度可能不同；升段、降段门槛也由客户端段位系统定义。
- 编写涉及段位分的内容时，应记录适用段位、东风/半庄、客户端版本或截图日期，避免把历史结算表写成固定规则。

## 8.7 天凤与雀魂段位场对照

以下是天凤平台段位场与本章默认雀魂段位场的规则差异。它们只在题目明确指定天凤时适用，不能覆盖雀魂基线。

| 项目 | 雀魂段位场 | 天凤段位场 |
|---|---|---|
| 三家荣和 | 默认一炮三响，三家分别结算，不流局 | 默认三家和了流局 |
| 国士抢暗杠 | 国士无双可以抢暗杠 | 国士无双不能抢暗杠 |
| 双倍役满 | 默认保留大四喜、四暗刻单骑等双倍役满 | 不采用双倍役满；大四喜、四暗刻单骑按单倍役满 |

天凤对照来自用户于2026-10-17补充确认；没有附带版本、牌局编号或原始牌谱，因此属于平台规则基线记录，不写成维护助手亲自执行的服务器实测。涉及其他天凤差异时，必须另行确认具体规则版本，不能由本表推导。
