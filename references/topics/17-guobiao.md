# 17. 国标麻将：编辑器所采用的规则

## 17.1 适用范围

本页对应来源README“功能概述”第3项。它是牌谱编辑器参考雀渣平台实现的国标模式，不是雀魂段位场，也不表示雀魂官方提供国标对局。来源作者明确提示可能存在实现错误。判定时先确认采用传统国标、雀渣平台还是该编辑器版本，不能只凭相同番种名称互相替代。来源与版本差异见 [证据索引](../replay-editor-rules-sources.md)。

国标问题使用本页的起和、计番和支付体系，不沿用立直麻将的符、基本点、满贯、累积役满、宝牌、立直、供托或本场。以下默认四人；比赛局数、起始分与结束条件需按实际赛制提供，不套用雀魂南四局终局算法。

## 17.2 和牌形与起和条件

通常和牌形仍为四个面子加一对将牌，杠按实际四张牌计数。另有七对、十三幺、全不靠／七星不靠及组合龙相关和牌形。七对允许四张相同牌作为两对，可另判四归一；不能沿用立直麻将“七种不同对子”的限制。

全不靠从三种花色分别对应的147、258、369，加七种字牌，共16种牌中选14种，每种一张；花色分配可置换。七星不靠要求七种字牌齐全。组合龙包含分属三种花色的完整147、258、369九张，再配一副面子及将牌；九张不能按三个普通同色顺子重新拆用。

默认要求**不计花牌至少8番**。先在同一种合法解释下确定番种、排除不允许重复的部分，再检查8番资格；最后加花牌。7番加一张花仍不能和牌。没有其他有效番种时才考虑无番和8番，不能用它给已有低番补足门槛。

本模式不采用立直麻将振听；合法和牌仍需满足牌形、行动时机及8番等条件。同一舍牌多人可和时采用截和／头跳，只成立距离放铳者最近的一家。这是本玩法自身的规则，不是本次排除的立直麻将“有无振听”自定义选项。

### 与立直麻将容易混淆的条件

| 国标番种 | 本模式应采用的条件 |
|---|---|
| 平和2番 | 四组顺子、数牌将牌；可副露，不要求两面听；不再计无字 |
| 一般高1番 | 两组同色同序顺子，可副露；允许的重复次数受套算规则限制 |
| 全求人6番 | 四组面子均副露，点和最后的将牌；不再计单钓将，暗杠不能充作明副露 |
| 门前清2番／不求人4番 | 通常门前点和计前者、门前自摸计后者，不能叠加；本身排除门清奖励的七对等特殊番型，自摸可另计自摸1番，不能再补不求人4番 |
| 九莲宝灯88番 | 要求九面听的九莲形，即立直麻将的纯正九莲条件；十三幺88番不因十三面听再翻倍 |
| 连七对88番 | 同一花色连续七种数牌各一对，不限于2345678；不再叠加清一色、七对等包含项 |
| 推不倒8番 | 仅用 `1234589p245689s5z`，不再计缺一门 |
| 边张／坎张／单钓将 | 需检查和牌前全部待牌及分解，不能仅看选出的一个面子；例如12345等3或6，不因3可解释成边张就计边张 |
| 杠上开花8番 | 杠后补牌自摸；可与最后一张牌的妙手回春复合，补花自摸不算杠上开花；不再计自摸 |
| 抢杠和8番 | 按本模式合法抢加杠处理，不将立直国士抢暗杠选项移植过来；不再计和绝张 |
| 开局扩展 | 天和为庄家起手和；地和为闲家点和庄家首张舍牌；人和为闲家首次摸牌前点和其他闲家首张舍牌，或首次摸牌自摸；均检查此前是否有破坏条件的操作 |

“海底捞月”在本模式指最后舍牌点和，“妙手回春”才对应立直的海底自摸。名称相同不代表条件相同。

## 17.4 计番原则与常见排除

按以下原则选取最高的**合法**总番，不将几套互不兼容的分解拼成一个结果：

1. 不重复：高番已包含的小番不再计。例如清一色不计无字，碰碰和不与已排除它的四暗刻重复，三色三同顺不再拆计其中的喜相逢。
2. 不拆移：选定一组面子的解释后，不能为另一番种把其中牌张拆走重组；可以比较不同完整解释，选择得分较高者。
3. 不得相同：已合成一种组合番的相同面子组，不再原样重复套用另一种同类组合；并非一个面子永远只能参与一次计番。
4. 就高不就低：同一解释有大小包含关系时取适用的高番，但不能为凑高番忽略和牌前的实际待牌或明暗属性。
5. 套算一次：主要约束一般高、喜相逢、连六、老少副这四类由两副顺子组成的小番，不是所有番种的通用“每副面子只能用一次”。

对四副顺子，上述四类小番合计最多三次；三副顺子最多两次。若三副顺子已组成清龙、花龙等组合，剩余顺子最多再与其中一副计一个适用的小番；四副顺子已整体构成一色双龙会等，则按该番型的排除规则，不另拆小番。

例如两副234万、两副234筒加将牌，可计一般高两次，再计喜相逢一次，不能把所有万筒配对各算一遍。又如123万、456筒、789索已计花龙，另有456万时，可以另取喜相逢或连六一次，不能二者都加。

不能将三杠与三暗刻一概视为套算冲突；杠数与暗面子数是不同属性，应检查实际明暗及明确的排除项。组合龙与平和也不能只凭九张“看起来不连续”就否定，必须使用该模式对组合龙的专门解释。

## 17.5 支付与例子

设F为通过8番资格检查后的有效总番，含最后加入的花牌。以未放大的计分单位：

| 和牌方式 | 各家支付 | 和牌者收入 |
|---|---|---|
| 自摸 | 其他三家各付 `8＋F` | `3×(8＋F)` |
| 点和 | 放铳者付 `8＋F`，另两家各付8 | `24＋F` |

这里的8是每家基础支付单位，不是立直麻将的满贯，也不是仅由放铳者支付的公共起和费。庄闲支付相同。编辑器默认把点数乘100以便展示；倍率只作用于点数，不把8番变成800番。

具体8番点和例：和牌前手牌 `23m456p678s11z`，副露碰 `555z`，和牌张 `4m`。五门齐6番加白箭刻2番，满足8番；23万为1／4万两面，不另计边坎单。点和时放铳者付16、另外两家各付8，和牌者共收32；默认放大100倍即1600＋800＋800＝3200。同样F＝8的自摸则三家各付16，共收48，放大后4800。自摸是否额外成立其他番，须重新判定，不能只替换同一牌例的和牌方式而固定F不变。

## 17.6 编辑器选项、花牌与版本边界

| 设置 | 说明与默认边界 |
|---|---|
| `_guobiao` | 明确开启本模式；不与立直的宝牌／符番体系混算 |
| `_guobiao_no_8fanfu` | 演示用放宽8番限制；默认不启用。低番展示牌谱不是正常8番起和的反例 |
| `_guobiao_lianzhuang` | 演示用允许连庄；默认不连庄。不能把样例中开启此项当国标通则 |
| `_scale_points` | 显示点数倍率，默认100；实际对局需记录倍率 |
| `_guobiao_huapai` | 扩展花牌功能，需来源的附加组件；用八张 `0m` 作花牌占位，不是八张红五万。补花后花牌另列，不组成手牌面子，手中仍有未补花不能和牌 |
| 错和处理 | 来源默认不足8番或不合法和牌向每家赔10个未放大单位；停和陪打需另设 `_cuohupeida` 及附加组件。这是本模式自身的错误处理，不扩展本次排除的立直无役诈和开关 |

本地花牌占位会导致“听5万时花牌也显示为危险牌”的显示问题。首巡摸到花再补花自摸，本地仍可能计人和，而雀渣公开说明不计人和，应明确报告实现差异，不以回放显示反推规则。

2026-10-15联网读取的 [雀渣计分页](https://tziakcha.net/scoring) 已列出本地目录没有的一色三连环16番、一色四连环32番。它说明参考平台继续演化，不代表旧编辑器自动支持这两项，也不能据此修改传统81番种目录。具体平台对局还应核对其 [规则页](https://tziakcha.net/rule/)。
