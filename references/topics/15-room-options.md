# 15. 友人房、比赛房与包杠

## 15.1 适用方式

本页整理用户指定编辑器README“功能概述”第1项中的可选规则。默认 [四麻段位](../rules-sources.md) 和 [三麻段位](../sanma-rules-sources.md) 不因本页出现某选项而改变。判定前记录人数、启用选项、数值与单位；只替换明确指定的规则，其余沿用该玩法基线。

下表的字段用于识别旧编辑器配置，不是要求用户编程。下划线开头的字段是编辑器自定义表达；文档列出的官方字段名只作为来源线索，不能假设当前客户端、所有房间和所有人数都提供同一设置。尤其反向命名如 `_no_yifa`，不能直接复制布尔值给 `have_yifa`。证据与实现差异见 [扩展规则来源](../replay-editor-rules-sources.md)。

## 15.2 友人房选项

| 选项 | 规则说明 | 旧编辑器标识／边界 |
|---|---|---|
| 雀魂古役 | 仅明确启用时增加对应役，番数、门清与替换关系见 [古役专题](14-guyi.md) | `guyi_mode`；一番街古役不在本次范围 |
| 赤宝牌数量，包括全赤 | 红五仍是普通五的一个实体副本；普通五与红五合计不得超过四张。增加红五不增加总牌数 | `dora_count`；四麻常见3枚为每色1枚，4枚为万1／筒2／索1，全赤为三色各4枚共12枚；三麻仅筒索各4枚共8枚 |
| 食断 | 开启时断幺九允许副露；关闭时只有门清断幺九有效。关闭后仍可凭役牌等其他役和牌 | 编辑器 `_no_shiduan` 为禁用标志；不能误读字段名称的正反含义 |
| 番缚 | 需要达到指定的起和番数。先检查非宝牌的有效役与番数，再加入宝牌，宝牌不能补足起和资格 | `fanfu`，通常为1；两番缚时，只有1番役加若干宝牌仍不够，本地判役在加入宝牌前检查 |
| 负分立直 | 放宽立直的点数限制，不放宽门清、听牌、牌山余量或立直后操作限制 | `_fufenliqi`；不会自动关闭飞人规则，也不能让已终局对局继续 |
| 三麻有无自摸损 | 有自摸损时缺席北家的应付部分不收；无自摸损时该部分由其余两家均分 | `_no_zimosun`；按 [三麻支付](13-sanma.md) 计算，荣和不受影响，不改本场总额 |
| 公开手牌 | 改变信息可见性，不等于副露，不自动破坏门清、立直或暗刻 | `open_hand`；与只公开起手牌的配牌明牌活动分开处理 |

红牌配置要给出各花色实际枚数，不能将任意总数理解为任意分配。本地实现对部分总数采用整除分配、并对四麻4枚单独处理；这不是允许任意不均匀分配的通用协议。

## 15.3 金额与普通计分选项

| 选项 | 如何改变判定或结算 | 旧编辑器字段／文档中的对应字段 |
|---|---|---|
| 自定义立直供托 | 按指定金额扣除立直费用并加入公共供托；仍单独检查支付能力与立直成立时点。终局归属与多人和牌领取顺序不由金额改变 | `_liqi_need` 以1000点为一单位；来源文档对应 `liqibang_value` |
| 自定义本场点数 | 先明确本场总额还是每位付款金额，不能把倍数当点数。编辑器倍率为B、本场n：荣和本场为 `(人数−1)×100×n×B`，自摸每家付 `100×n×B` | `_ben_times` 为倍率；来源文档列 `changbang_value`，单位应以实际房规核对 |
| 自定义不听罚符 | 按听牌人数选择相应金额，在听牌／未听牌两组之间转移；全听或全不听不转移，合计必须守恒 | `noting_fafu_1/2/3`；本地实现将值解释为该听牌人数下每位未听者的付款，并均分给听牌者 |
| 切上满贯 | 开启时30符4番、60符3番按满贯结算；不能把其他不足满贯的组合一并切上 | `have_qieshangmanguan`；关闭时仍为7700／11600等通常点数 |
| 连风4符 | 同时为场风、自风的雀头，开启时计4符，禁用时计2符；只改变符，不增加一个役 | `disable_double_wind_four_fu`，正值表示取消4符 |
| 累积役满 | 开启时普通役合计13番以上为单倍累积役满；禁用时普通番数最高按三倍满，不能因此取消自然役满 | `disable_leijiyiman` |
| 双倍役满 | 禁用时大四喜、四暗刻单骑、纯正九莲宝灯、国士十三面各按单倍；独立自然役满仍可复合 | `disable_double_yakuman`；与另一个“禁止役满复合”选项不是同一件事 |
| 人和满贯 | 子家首次摸牌前、无人鸣牌时荣和，采用5番人和；不是雀魂古役中的单倍役满人和 | 编辑器 `_renhumanguan`；文档列 `enable_renhe` 0关闭／1满贯／2役满。本地实现按5番加入普通计分，并非无条件锁死总额为满贯 |

金额例：四麻将每位未听者付款设为1200点，两听两未时，两位未听者各−1200，两位听牌者各+1200；一听三未时，唯一听牌者+3600。三麻两听一未若该金额为2000，则两听者各+1000。不能将 `noting_fafu_2 = 2000` 理解为每位听牌者必得2000。

立直费、本场、罚符是三类不同资金。无自摸损只补北家缺席的和牌支付；调整立直费用不改变立直的役番；调整本场不改变役的成立与基本点。[多人荣和与供托](04-scoring.md#honba-deposits) 仍须先确认是否头跳或三家和了流局。

## 15.4 行动、流局与宝牌选项

| 选项 | 规则说明 | 旧编辑器标识 |
|---|---|---|
| 头跳 | 同一舍牌有多家合法荣和时，只让从放铳者起按逆时针顺序最先的和牌者成立；不是按当前名次选择 | `have_toutiao` |
| 三家和了流局 | 开启时三家同时荣和触发途中流局；默认雀魂段位不采用，按一炮三响结算 | `have_sanjiahele`；若同时存在头跳，头跳先截为至多一家和牌，因此不会再触发三家和了流局 |
| 流局满贯 | 禁用时不结算流局满贯，转按适用的普通荒牌规则处理；开启时成立条件及后续仍见 [荒牌流局](02-game-flow.md#nagashi) | 编辑器 `_no_liujumanguan`；来源文档对应 `have_liujumanguan`，极性相反 |
| 一发 | 禁用时不计一发这1番，立直本身仍有效；不要因此改变摸打顺序 | `_no_yifa`；来源文档对应 `have_yifa`，极性相反 |
| 表宝牌 | 决定初始表指示牌产生的宝牌是否加番，不把指示牌本身当作宝牌 | `_no_dora`／`have_biao_dora` |
| 里宝牌 | 只有适用规则下的立直和牌者才检查里宝；关闭不影响立直本身 | `_no_lidora`／`have_li_dora` |
| 杠表宝牌 | 决定开杠额外表指示牌产生的宝牌是否加番 | `_no_gangdora`／`have_gang_biao_dora` |
| 杠里宝牌 | 决定开杠额外里指示牌产生的宝牌是否加番，与初始里宝分开 | `_no_ganglidora`／`have_gang_li_dora` |
| 杠表宝牌即翻 | 改变大明杠／加杠通过后的翻表指示牌时点，使本次岭上自摸也可能使用新增杠宝牌；抢杠响应仍先于杠成立与补牌 | `ming_dora_immediately_open`；暗杠默认已是通过后即翻，详见 [杠时序](09-call-kan-rules.md#kan-timing) |
| 国士无双抢暗杠 | 禁用时国士也不能抢暗杠；不因此禁用通常的抢加杠 | `disable_angang_guoshi` |

四种宝牌开关与赤宝牌数量分开核对。关闭表宝牌不自动表示无赤宝牌；宝牌不能作为起和役。对任意组合先按开关确定有效指示牌，再计宝牌，不把本地实现的联动当通用规则：例如旧实现关闭杠表时也限制杠里指示牌数量，详见来源记录。

## 15.5 责任支付与包杠

### 役满责任选项

关闭大三元／大四喜包牌时，役满仍成立，只取消责任转移。开启四杠子包牌时，按本地实现由提供第四个大明杠的玩家承担四杠子部分；最后一杠为暗杠或加杠不能凭空指定放铳者。

来源文档将 `enable_baopai_extend_settings` 描述为0无包牌、1大三元／大四喜、2另含四杠子；编辑器分别使用 `_no_normalbaopai` 与 `_sigangbaopai`。修罗／万象修罗不设这些包牌，不能因额外开关存在而覆盖其模式限制。复合时仍按 [责任部分与非责任部分分开](05-special-rules.md#pao) 处理，不把整手役满都归给同一个责任者。

### 包杠

本页“包杠”特指来源中的自定义规则：玩家大明杠他家的舍牌后，以相应的岭上摸牌自摸，则被杠者承担本应分摊的支付，视为该次自摸的等效放铳者。连续岭上摸牌的链条可以保留责任；切牌后该链结束。暗杠、加杠本身不新增一个被杠责任者，抢杠荣和也不是这个规则的触发方式。

`_baogang` 不属于默认段位规则，仅适用于来源所述的非修罗立直玩法。它与“大明杠导致第四杠的四杠子包牌”有不同的触发条件，也与赤羽之战即时收取杠分不同。

| 自摸的组成 | 启用包杠后的支付 |
|---|---|
| 没有役满包牌部分 | 包杠者承担全部和牌基本支付 |
| 含有役满包牌部分 | 各役满责任者承担各自部分，非包牌部分由包杠者承担 |
| 本场费 | 包杠者支付全部本场；不重复让其他人再支付一份 |
| 公共供托 | 由和牌者领取既存供托，不把它当作责任者新增的支付 |

例如四麻子家大明杠后岭上和牌，已算得基本和牌额8000点，两本场且本场倍率1，无役满包牌：包杠者付8600，另外两家不付，供托另算。若同一人兼具两种责任，先分项算清再合并收支；三麻还须按已确认的自摸损口径计算，不能将“等效放铳”误用成荣和不扣损。

## 15.6 判定所需输入

至少记录适用玩法与人数、各开关的实际取值、金额单位、和牌前手牌／和牌张／面子、和牌方式与行动时序。涉及责任支付要能定位触发鸣牌的提供者。若同时启用头跳与三家流局，或混用不同活动规则，应指出具体未确定的交互，不能仅凭“编辑器能设置”宣称官方支持该组合。

本次不扩展一番街古役、青天井、立直麻将的有无振听开关及无役诈和选项；活动、川麻或国标自身的规则差异仍按各专题说明。
