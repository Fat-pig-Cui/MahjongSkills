# 7. 注意事项（规则边界）

<a id="furiten-response"></a>
## 7.1 振听与见逃

| 条件                 | 结果              | 例外/解除             |
|--------------------|-----------------|-------------------|
| 自己的舍牌记录中有当前任一种荣和牌 | 舍张振听，不能荣和 | 改变听牌形且新听牌不含已舍牌时解除 |
| 非立直时放过他家打出的当前待牌 | 同巡振听，不能荣和 | 下一次自己舍牌后解除 |
| 立直后放过他家打出的当前待牌，或因振听不能对该舍牌荣和 | 立直后振听，至本局结束不能荣和 | 自摸始终可和 |
| 放过抢暗杠、抢加杠或抢北响应 | 不因此新增振听 | 已有振听仍限制这些荣和方式 |

- 上表针对舍牌的“放过”包括主动不荣和、无役无法和牌、因自己处于振听而无法荣和；不能将这一定义扩展到杠或拔北响应。
- 暗杠、加杠和拔北的牌不纳入舍张振听。大明杠则先有普通舍牌，放过该舍牌仍按舍牌规则判定；该牌随后被鸣走也不撤销已触发的振听。
- 振听只限制荣和，不影响自摸、听牌状态和立直本身。
- 未新增振听不代表保留一发：无人抢杠后完成的杠、无人抢北后完成的拔北仍中断一发。完整定义及确认来源见 [游戏流程](02-game-flow.md#riichi-furiten)。

## 7.2 立直后暗杠

- 立直后不得吃、碰、明杠或加杠。
- 立直后仅可对自己摸到的第四张相同牌暗杠，且暗杠前后听牌种类不得改变；面子构成是否变化不影响暗杠是否合法。
- 暗杠会中断其他立直者的一发；补牌和翻指示牌的时序见 [鸣牌与杠](09-call-kan-rules.md#kan-timing)。

## 7.3 途中流局条件

| 事件   | 条件                            | 结果                         |
|------|-------------------------------|----------------------------|
| 九种九牌 | 无鸣牌、第一巡自己的第一次摸牌后，持有九种或以上不同幺九牌 | 可自行宣告流局；不宣告可继续打            |
| 四风连打 | 四人第一张舍牌同为同一种风牌，且无人鸣牌          | 途中流局                       |
| 四家立直 | 四名玩家均成功立直                     | 途中流局；若第四家立直的宣言牌被荣和，和牌优先    |
| 四杠散了 | 不同玩家累计第四杠通过抢杠判定，且开第四杠玩家后续舍牌未放铳 | 通常途中流局；一人独自完成四杠并可能四杠子和牌是例外 |

<a id="action-priority"></a>
## 7.4 和牌、抢杠与流局优先级

1. 舍牌出现后，荣和优先于吃、碰、明杠。
2. 加杠宣言后、杠者岭上摸牌前，其他玩家可抢杠荣和；国士无双可抢暗杠, 国士无双十三面理论上也可以但因为不存在第五张同样的牌, 所以遇不到。
3. 抢杠成立时不完成该次杠，因此不触发该杠的岭上摸牌、杠宝牌或四杠散了。
4. 不同玩家累计至第四杠时，先完成抢杠判定；抢杠失败且杠成立后，第四杠的后续只能是岭上自摸或舍牌，不能再次开杠或拔北。
5. 暗杠通过后先翻新宝牌指示牌，再岭上摸牌；岭上自摸立即和牌。若选择舍牌，舍牌荣和立即结束；舍牌通过后才四杠散了。
6. 大明杠／加杠通过后先岭上摸牌；若岭上自摸立即和牌，不翻该杠的新指示牌。若选择切牌，紧接着翻该杠的新指示牌，再判断舍牌响应；若放铳则按荣和结束，否则进入四杠散了。
7. 通常牌山仅剩最后一张时，暗杠、加杠与大明杠均不可宣告；最后一张通常舍牌可以河底荣和。

四麻段位场允许一炮三响：三家对同一舍牌荣和时按和牌分别结算，不触发“三家和了流局”。本场和供托归属见 [计分](04-scoring.md#honba-deposits)，各家的和牌资格不受归属规则影响。上述第四杠优先级适用于三麻共通规则；一人独自完成四杠不触发四杠散了。具体事件序列见 [第四杠示例](../examples/gameplay.md#fourth-kan-examples)。

## 7.5 易混淆的限制

- 鸣牌后面子固定，不能将已副露的牌重新拆组；但仍可用手牌重组未副露部分。
- 暗杠不破门清，明杠会破门清, 加杠因为之前需要碰, 所以也不会是门清状态。
- 双立直要求第一轮舍牌前无人鸣牌；任意鸣牌会使之后的首巡立直不再满足双立直。
- 天和、地和会被鸣牌或非规定的首巡动作中断。
