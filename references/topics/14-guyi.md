# 14. 雀魂古役

## 14.1 适用范围与判定顺序

古役是特定玩法额外启用的役，不属于默认段位规则。雀魂公开规则说明为本页14个役逐项标注了“段位场不使用”；只有题目、房规或牌谱明确启用雀魂古役时才使用本页。没有说明启用时，仍按 [通常役种](03-yaku-han.md) 判定。

本页针对雀魂的古役集合，不把其他日麻地方规则或编辑器的“一番街特色古役”加入其中。“乱斗之间”是本地专题记载的历史使用场景，公开配置中保留的模式ID为13（四东）、14（四南）；这不表示该活动目前仍开放，也不表示只有这两个ID能使用古役。本地示例牌谱通过 `detail_rule.guyi_mode = true` 表示启用。

判定时依次确认：古役是否启用 → 和牌是否合法（荣和须未振听）→ 和牌形与事件条件是否成立 → 对每种合法分解分别计算复合 → 选择最高点数的解释。古役本身可以满足有役要求，但不能解除振听对荣和的限制、非法鸣牌或行动时序限制。条件役需要事件记录，不能仅凭14张牌判断。

名称、番数与门清限制以官方公开配置中的中文说明为依据；编辑器只补充实现线索。来源、冲突与尚未获得服务器证据的边界见 [古役证据索引](../guyi-rules-sources.md)。

## 14.3 依赖行动时点的役

### 燕返

和的是别家宣告立直时打出的那张牌。官方特别注明“仅第一张的宣言牌”，不能把立直者之后的摸切牌也视为宣言牌。和牌者自己不必立直，也不必门清。

重点是这次舍牌事件，而不是放铳者最终是否进入立直状态。不要把宣言牌被荣和与立直成立后的一发混为一谈；一发检查的是和牌者自己的立直状态。燕返也不是“抢杠”的别名。

### 杠振

事件顺序为：别家开杠成立 → 该玩家岭上摸牌 → 该玩家切牌 → 自家荣和该舍牌。开杠可为暗杠、大明杠或加杠；若连续开杠，观察最后一次杠后的这张舍牌。中间一旦转为其他玩家的普通摸打，不能继续追认杠振。

| 实际和牌时点 | 判定 |
|---|---|
| 杠尚未通过，直接荣和用于加杠的牌 | 按抢杠检查，不是杠振 |
| 开杠者用岭上牌自摸 | 按岭上开花检查，不是杠振 |
| 开杠者岭上摸牌后打出一张，自家荣和 | 可以成立杠振 |
| 杠后已经经过其他人的普通摸打，再荣和 | 不因此成立杠振 |

翻杠宝牌、第四杠后是否途中流局仍按 [杠的时序](09-call-kan-rules.md#kan-timing) 与 [行动优先级](07-edge-cases.md#action-priority) 分别判断。杠振的和牌张来自牌河，其振听判定按普通舍牌荣和处理，不能套用“放过加杠不进入振听”的例外。

### 一筒摸月与九筒捞鱼

先按通常规则确认是海底摸月或河底捞鱼，再检查和牌张：自摸1筒对应一筒摸月，荣和9筒对应九筒捞鱼。仅仅手牌中有1筒／9筒不成立，岭上自摸1筒也不因此成立一筒摸月。

这两个役各贡献5番，并非把总支付固定为满贯。本地实现将一筒摸月替换海底摸月、九筒捞鱼替换河底捞鱼，因此不再重复增加对应的1番；其他成立的普通役与宝牌继续累计。例如门清一筒摸月至少还有门前清自摸和，总计至少6番，按跳满起算。成立自然役满时，不再把这些普通番数加到役满上。

### 人和

必须是子家，且在自己第一次摸牌前荣和；从开局到和牌之间无人鸣牌。吃、碰、杠都会破坏这里要求的开局状态，暗杠也不能因为“不破门清”就忽略。自己第一次摸牌后，即使尚未打出第一张牌，也已失去人和的时间窗口。

不要混同三个开局役满：庄家配牌和牌检查天和；子家无人鸣牌时第一次摸牌自摸检查地和；子家首次摸牌前荣和才检查人和。雀魂古役的人和为役满，不采用其他地方规则中的满贯或若干番版本。

### 石上三年

条件是“双立直 + 海底摸月”或“双立直 + 河底捞鱼”。双立直成立后不要求整局持续无人鸣牌：开局时的双立直资格与终盘的海底／河底时点分别检查。普通立直加海底、连续连庄三次或立直后三巡和牌，都不等于石上三年。

海底自摸与河底荣和均可成立；荣和仍须未振听。若以1筒海底自摸或9筒河底荣和，已经按石上三年的自然役满结算，不再另加5番。其他独立自然役满满足条件时，按自然役满复合规则处理。

## 14.4 依赖牌形的役

### 十二落抬

必须已有四组吃、碰或明杠／加杠面子，手牌只剩一张，等待另一张组成雀头；自摸和荣和都可以。暗杠不计入这里的“四副露”，所以三组明面子加一组暗杠并不满足条件。杠子虽有四张，仍只占一组面子。

这是1番役，不采用其他地方规则中“必须单骑荣和”“自摸另称独钓”或“只能吃碰、不能明杠”的版本。

### 五门齐

“五门”是万、筒、索、风牌、三元牌这五类，不是五种具体牌。和牌的手牌与固定面子合并后，每类至少出现一种即可；风牌或三元牌可以只作雀头，不要求全部为刻子，也不要求是场风或自风。

七对子也可具备五类牌，例如 `11m22p33s11225566z`。但不能把其他玩家的舍牌、宝牌指示牌或已经拔出的北算进自己的和牌形。

### 三连刻与一色三同顺

三连刻要求同一花色的连续三种数字各组成刻子或杠子，例如333、444、555万；111、222、333字不成立，因为字牌不按数字连续成组。杠可以作为对应刻子使用，不要求这三组都是暗刻。

一色三同顺要求同花色、同起点的三组顺子，例如三组345万；123万、123筒、123索属于三色同顺。只要破门清，该役由3番降至2番。它可以与二杯口复合；判断时仍需在同一个完整分解中确认四组顺子及门清状态，不能把三组顺子拆去后再和另一种分解拼接。它不再额外重复计算其中的一杯口，但四组完全相同顺子仍可按二杯口计算。

同一批牌可能有不同分解。例如 `333444555m789p66s` 可以解释为三组345万，也可以解释为333、444、555万三个刻子。必须在各自分解内判役和计符，再比较总点数，不能把前一种解释的一色三同顺与后一种解释的三连刻同时相加。四组完全相同顺子时与二杯口的特殊复合，见证据索引中的边界说明。

### 大车轮、大竹林、大数邻

三者仅花色不同，分别限定筒、索、万的2至8各两张。必须门清，按七对子牌形识别；即使同一组牌也能拆成四顺子一雀头，也不影响该特殊牌形成立。换成1至7、3至9或混用花色，都不成立。

不能先吃成几组顺子，再因全牌统计仍是2至8各两张而判役满。这里以官方明确的“门前清限定”为准；本地编辑器有缺少显式门清检查的分支，不作为取消限制的依据。

### 大七星

东南西北白发中各一对，即 `11223344556677z`，门清限定，雀魂配置标为双倍役满。四张同一种字牌不能拆成两个对子，含刻子或杠子的字一色也不等于大七星。

大七星是字一色的上位替代，因此采用双倍结算，不另叠加字一色变成三倍；七对子也不再计普通番数。独立成立的天和、地和、人和或石上三年等自然役满，仍分别检查成立条件。若房间另有禁用双倍役满或禁止役满复合的选项，须先核对具体模式，不从本页默认推定其特殊降级行为。

## 14.6 计分、三麻与平台边界

普通古役按番数加入普通役与宝牌的合计；符数、等级、本场、供托仍见 [计分](04-scoring.md)。人和等自然役满使用役满基本点，大七星使用双倍；不要把配置中的13／26番字段误当作累积役满。古役没有因此新增责任支付触发条件：涉及大三元、大四喜等复合时，只对 [责任规则](05-special-rules.md#pao) 指定的责任部分结算。

段位三麻同样不使用古役。现有专题、示例和模式记录不能证明雀魂提供三麻古役房。若明确讨论“在三麻牌组下额外启用这些古役”的理论扩展，必须标为自定义假设，再应用 [三麻差异](13-sanma.md)：缺少2至8万使大数邻不可能；不能吃、拔北及补牌时点也会影响其他役的实现路径。不能把四麻牌例直接套入三麻，更不能推称两者组合数相同。

八连庄虽在官方 `fan.fan` 中保留ID46，但用户指定专题注明未实装，本地实现也只在“一番街特色古役”分支判定；仅有名称和番数不能证明雀魂古役采用它。推不倒、赤三色、三色通贯、四连刻、一色四同顺、红孔雀、红一点、黑一色、十三不搭、百万石、金门桥、东北新干线、无发绿一色等同样不加入本页集合。
