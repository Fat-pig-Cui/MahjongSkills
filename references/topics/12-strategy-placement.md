# 12. 攻守与终局策略

> 本章将规则转化为顺位判断。段位场的目标是最终排名，不是单局最高得点；赛制与终局条件见 [段位赛赛制](08-match-rules.md)。

## 12.1 四个决策变量

任何立直、鸣牌、默听、押回或弃和决策都至少比较：

| 变量 | 需要问的问题 |
|---|---|
| 速度 | 当前向听、受入、巡目、对手是否已立直或副露？ |
| 打点 | 役、宝牌、亲番、本场、供托和自摸/荣和概率有多大？ |
| 放铳风险 | 现物、筋、壁、对手牌河与副露透露什么？ |
| 顺位价值 | 和牌、放铳或流局分别会怎样改变一至四位？ |

只比较番数会忽略速度和顺位；只比较受入会忽略放铳与终局条件。

## 12.2 立直、默听与鸣牌

- **立直**适合门清、待牌较好、可借里宝和一发提高打点，或需要施压阻止他人进攻的局面。立直会锁定手牌并暴露进攻意图。
- **默听**适合已经足够打点、待牌过于显眼、需要保留安全牌，或立直后放铳会严重影响顺位的局面。
- **鸣牌**适合能明显缩短和牌速度、确保役、抢庄或完成明确的顺位目标；鸣牌会降低门清役、里宝与手牌弹性。
- 不应只按“门清必立直”或“鸣牌必快攻”决策。比较立直后可和牌点、默听荣和限制、鸣牌后的役与待牌。

## 12.3 亲番、本场与供托

- 庄家自摸由三家支付，荣和点数也更高；亲番的进攻价值通常高于闲家。
- 本场会提高和牌价值：荣和每本额外300点，自摸每本由每名对手额外支付100点。高本场时小和也更有速度价值。
- 桌面立直棒是额外的固定收益。多根立直棒会使先和者价值大幅提高，但不应为争供托而无视高放铳风险。

## 12.4 点数状况的基本目标

| 局面 | 优先目标 |
|---|---|
| 大幅领先且非亲 | 降低放铳，避免给追赶者大牌；可接受小和或流局 |
| 大幅领先且亲 | 在安全前提下利用亲番扩大优势，但不要为了连庄承担不必要风险 |
| 二、三位接近 | 明确计算与相邻顺位的点差，避免为了争一放铳跌四 |
| 落后但仍可小和逆转 | 优先速度和确定役，必要时鸣牌 |
| 大幅落后 | 计算最小逆转点，不足时才寻求高打点路线；不要在无望路线中拖慢速度 |

## 12.5 All Last 与目标分

1. 先计算与目标顺位的实际点差，加入本场、立直棒、亲子支付和可能自摸的总收支。
2. 写出“和牌所需最低条件”：例如子家荣和需要3900、亲自摸需要每家多少，或必须直击特定对手。
3. 判断是否应快速小和、保留门清冲打点、鸣牌直击，或完全弃和保住当前顺位。
4. 最后一局结束后才确定排名；仍要考虑庄家连庄、飞人、延长/西入和同点顺位。

## 12.6 防守优先的典型情形

- 自己一向听但受入很小、无役或打点低，而对手早巡立直且有大量现物。
- 自己已领先，放铳一次会失去目标顺位，和牌收益却无法扩大或巩固优势。
- 末巡接近荒牌流局，自己听牌即可获得罚符或保住顺位，没必要为改良冒险。
- 对手是亲家、明显混一色/对对和副露、宝牌周边集中，潜在失点远大于自己的和牌收益。
