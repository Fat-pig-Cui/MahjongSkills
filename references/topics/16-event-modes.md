# 16. 雀魂活动玩法

## 16.1 适用范围与玩法索引

本页覆盖用户指定README第1项中的修罗之战、赤羽之战和13种其他活动。模式ID与字段用于识别所讨论的历史配置，不证明目前仍开放、仍常驻或能在任意房间启用。完整来源、公开配置ID与本地实现差异见 [扩展规则证据索引](../replay-editor-rules-sources.md)。

先确定玩法，再判断牌组、行动、起和资格、普通计分及活动加成；供托、本场、罚符单列。公开信息的改变不自动破坏门清；倍率不等于增加役番；奖励番未必能作为起和役。不能把各模式开关任意叠加，视为一套已经验证的官方规则。

## 16.2 修罗之战

配牌后各选三张交给另一家，按本局指定的方向交换；本地样例支持顺时针、逆时针或对家交换。使用通常立直麻将牌组和役种，一局到三人和牌或发生流局才结束。和牌即时结算，已和牌者退出本局后续通常摸打与支付，手牌不立即公开；出现飞人则整场结束。

不设连庄：无论庄家是否和牌、是否听牌，正常完成本局都进入下一局0本场。途中流局则本局0本场重开，先前已发生的和牌应与后续流局事件分开记录，不能把此前收支当作尚未结算。

已和牌者不参加荒牌罚符。修罗无人和牌且两人听牌、两人未听牌时，本仓库采用每位未听者支付1500点、每位听牌者收取1500点的口径；这是2026-10-17用户补充确认的裁定，覆盖本地专题与公开说明之间的差异。若已有一人和牌、剩余两听一未，按逐对1000点计算，未听者付2000，两听者各得1000。

抢杠与普通玩法有关键差别：可先结算抢杠和牌，再使杠成立，包含国士抢暗杠；若继而触发四杠散了，抢杠和牌仍成立，之后本局因途中流局重开。不能把普通段位“被抢则该杠不成立”的规则直接套入。

立直宣言牌放铳时，先付此次和牌点数，再判断剩余点数是否足够支付立直费。按1000点立直费，剩至少1000才可成立；不足则当普通舍牌继续，负分则按飞人结束。大三元、大四喜不设包牌，也不套用本仓库默认的包杠扩展。

## 16.3 赤羽之战：川麻规则

### 牌组与对局流程

使用万、筒、索各36张，共108张；无字牌、赤宝牌、宝牌指示牌和王牌。本地默认起始50000点。配牌后交换三张同花色牌，并为每位玩家确定一种不要的花色，称为定缺；和牌形中仍含定缺花色则不能和牌。

不能吃、不能立直，采用此模式自身的无振听规则，可碰、开杠。三人和牌或荒牌结束本局，支付实时进行，已和牌者退出；飞人结束整场。无连庄，共打四局；本局第一位和牌者在下一局为东风位，不能照搬段位场的固定轮庄算法。

### 和牌番型与支付

番数采用此模式的数值，不使用立直麻将符番公式。基础／复合番型取对应的成立项，再加入允许的奖励番；不能把“清对4番”另与对对和2番、清一色3番相加。

| 基础或复合番型 | 番数 | 识别要点 |
|---|---|---|
| 底和 | 1 | 无更高基础番型的普通合法和牌 |
| 对对和 | 2 | 四组刻子／杠子 |
| 清一色 | 3 | 仅一种数牌 |
| 七对子 | 3 | 七个对子；此模式四张相同牌可作两对 |
| 带幺九 | 3 | 各面子及将牌含1或9 |
| 金钩钓 | 3 | 四组碰／杠，最后等将牌 |
| 清对 | 4 | 清一色的对对和 |
| 将对 | 4 | 仅用2、5、8组成对对和 |
| 龙七对 | 4 | 七对子中有四张相同牌；已用于该番型的一根不再重复加 |
| 清七对 | 5 | 清一色七对子 |
| 清幺九 | 5 | 清一色带幺九 |
| 清金钩钓 | 5 | 清一色金钩钓 |
| 天和、地和 | 各6 | 本模式规定的开局自摸；地和不是国标的地和 |
| 清龙七对 | 6 | 清一色龙七对 |
| 十八罗汉、清十八罗汉 | 各6 | 四杠，后者另为清一色；四杠已含的四根不重复计 |

| 允许加入的奖励番 | 数值与条件 |
|---|---|
| 杠上花 | 杠后补牌自摸，+1番 |
| 杠上炮 | 荣和别家杠后打出的牌，+1番 |
| 抢杠 | 合法抢加杠，+1番；不采用国士抢暗杠 |
| 海底捞月 | 牌墙摸尽时和牌，+1番；此模式的显示名称同时用于自摸与点和 |
| 根 | 和牌形每有一种四张相同牌通常+1番；与龙七对、十八罗汉的包含关系先剔除 |

合计F番的基本支付额为 `min(1000×2^(F−1), 32000)`：1／2／3／4／5／6番对应1000／2000／4000／8000／16000／32000，6番封顶。点和仅向放铳者收基本额；自摸时向每位仍在场的其他玩家收“基本额+1000”。例如3番自摸、尚有三位对手时，每家付5000，总收15000；已有一家和牌退出时，仅余下两家各付5000。

### 杠分与流局

| 行动 | 立即支付的杠分 |
|---|---|
| 暗杠 | 每位仍在场的其他玩家付2000 |
| 大明杠 | 提供舍牌者付2000 |
| 用刚摸到的牌补杠 | 每位仍在场的其他玩家付1000 |
| 用原手牌补杠 | 不收杠分 |
| 补杠被抢 | 杠不成立，不收此笔杠分 |

流局时，已和牌者不参与以下项目。未听牌者退还本局收到的杠分，按原付款人逐笔返还。未听牌者向听牌者支付查叫金额，按该听牌者可能和牌的最高番型计算，不额外按自摸加1000。仍持定缺花色者为花猪，向其他未和牌者逐一支付至少4番的金额，若对应接收者的可能最高番数更高则取更高值。退杠、查叫、花猪分别计算，避免漏记或重复记账。

本地赤羽专题末尾还提出另一套“基础番+附加番”的自创解释；本页采用前述活动番表，不以那套自创拆分替代活动实际点数。

## 16.4 宝牌、公开信息与目玉

**宝牌狂热**：开局翻三张表宝牌指示牌，之后开杠最多增加至五张，达到上限不再增加。本地配置默认起始35000点。不是把一张宝牌直接改成三番。

**配牌明牌**：仅起始配牌对所有人可见，之后摸入的牌按通常方式保密。公开不等于吃碰，不破门清；不能凭此得知玩家后来摸入的同一种牌。不要与全程公开手牌选项混淆。

**龙之目玉**：同样起始三指示牌、上限五张，本地起始40000点。随机一位持有目玉标记；其累计打出五张通常舍牌后重新随机标记，可能再次选中本人，鸣牌不计作这五次打牌。持标记者和牌时基础收入加倍，放铳或支付他人自摸时其对应付款加倍；本场费和供托不翻倍。

**明镜之战**：每种四张牌中三张为透明牌，所有人可见，无赤宝牌，采用头跳。吃碰时可以选择使用透明或不透明的实体副本，不能只按牌种总数忽略这一区别。透明牌不破门清。本地编码用后缀`t`表示透明副本，该后缀是信息标识，不额外增加一张牌。

## 16.5 暗夜之战

| 阶段 | 操作者与费用 | 结果 |
|---|---|---|
| 暗牌 | 舍牌者支付1000 | 盖牌打出，其他人不能吃碰杠或荣和；不触发自己或他人的振听 |
| 开牌 | 其他玩家可支付2000 | 成功则该舍牌向所有人公开，恢复通常吃碰杠／荣和响应 |
| 锁定 | 舍牌者在有人要求开牌时支付4000 | 阻止公开，此牌永久盖住，不能再被吃碰杠或荣和 |

点数不足相应费用不能操作；暗牌并立直按标准费用至少需2000。多人同时要求开牌时，从暗牌者起按逆时针最先者支付开牌费用。已锁定不能再开牌，不把开牌请求本身当作成功公开。

这些费用进入公共供托，下一次和牌者领取；多人荣和时由放铳者逆时针方向最近的和牌者领取，整场无人领取的供托最后归第一名。它们不是新增加的番数，也不是支付给提出开牌的玩家。流局满贯只按非暗牌部分判断牌河，盖住的中张不因此破坏流局满贯。

## 16.6 幻境传说

每场从庄家卡、机会卡、命运卡各取一张，共同生效。下表依据本地专题，公开配置另核实了“三类各一张”的框架；具体卡片与交互不称为服务器实测。

| 类别 | 卡名 | 改变的规则 |
|---|---|---|
| 庄家 | 风纪 | 不改变立直成立条件；只限制庄家能否和牌，庄家门清荣和须已立直或副露，自摸不受此限制 |
| 庄家 | 永夜 | 庄家连庄本场+5；庄家未连庄的流局本场+1 |
| 庄家 | 没收 | 流局时场上立直供托归庄家 |
| 庄家 | 炒作 | 庄家每次碰／杠额外增加一张宝牌指示牌，上限四张 |
| 庄家 | 赠品 | 庄家荣和时每张宝牌额外增加1000点 |
| 机会 | 里世界 | 立直和牌时表宝无效、里宝两倍，赤宝照常 |
| 机会 | 三倍速 | 无人吃碰杠破坏时，立直后三巡均可计一发 |
| 机会 | 金闪闪 | 指示牌本身也算宝牌；其通常指向的宝牌仍有效 |
| 机会 | 超断幺 | 断幺九改为3番 |
| 机会 | 胜负手 | 立直2番、一发2番、双立直4番 |
| 命运 | 夸大其词 | 不听罚符及流局满贯支付两倍 |
| 命运 | 过度准备 | 立直费用改为2000 |
| 命运 | 厄运沙漏 | 立直宣言后每张舍牌使和牌点数减少300点，最低减至0；本场与供托不计入被减少的和牌点数 |
| 命运 | 暗中交易 | 吃、碰、大明杠时向舍牌提供者支付500点 |
| 命运 | 爱的代价 | 吃、碰、大明杠宝牌时支付2000点公共供托 |

识别码形如 `A0B0C`，A为命运卡、B为机会卡、C为庄家卡，各取1至5；例如10203对应夸大其词、三倍速、没收。金额加减、供托、宝牌、额外番分别计算，不能把300点减额当作减番；厄运沙漏只减少和牌点数，最低为0，本场与供托不参与扣减。额外宝牌时点或多效果交互若无独立口径，仍需保留具体条件。

风纪卡不改变立直条件，只改变庄家能否和牌；本地生成判役分支对该限制的判断与专题及代码注释相反，已在来源索引记录，不能用该分支的输出证明卡片规则。

## 16.7 占星之战与天命之战

**占星之战**：首次摸牌时公开接下来三张作为候选池。通常摸牌和岭上摸牌都从候选池任选一张，未选者保留；之后摸牌前按流程从牌墙补足至三张。牌墙剩三张及以下时停止补足，并禁止开杠，即使本地编辑器能继续构造杠也不应接受为活动合法操作。

候选池选择不取消地和、一发或岭上开花：仍按首次摸牌、立直后是否受鸣牌破坏、此次是否岭上摸牌分别判断。备选牌全程公开不表示已归任何人，没选入手的牌不能计入和牌形、宝牌数或自己的命运牌。此模式不能使用自动摸切。

**天命之战**：每位玩家最先摸入的四张牌带个人命运标记，对其他人可见。本地默认起始50000点。和牌形保留自己的标记牌数量为k时，普通和牌支付乘以 `k+1`，k为0至4；手牌和副露中的自己标记牌均可计入。打出的命运牌失效，在牌河中与普通牌相同，不能将他人的标记转成自己的加成。

本场、立直供托、不听罚符不参与天命倍率。牌种相同但实体标记不同应分别追踪；本地后缀`t`在此代表命运标记，在明镜之战代表透明牌，两者不能跨模式自动互换含义。

## 16.8 咏唱之战与魂之一击

咏唱之战分别取本局最长连续摸切段、最长连续手切段，按达到的最高档奖励，不累计多个短段，也不把各档逐项相加。

| 奖励 | 连续张数门槛 | 对应加番 |
|---|---|---|
| 绯：摸切 | 3／5／7／9／12 | 1／2／3／5／12 |
| 苍：手切 | 3／6／9／12／18 | 1／2／3／5／12 |

不足最低门槛为0。和牌时两种奖励相加，但不能用来起和，仍须有通常成立的役；摸切在牌河中变暗只是显示效果，不等于暗夜的盖牌。记录手切／摸切必须保留动作信息，不能根据牌种相同就假定一定摸切。

魂之一击把立直改为2番、双立直改为3番。立直成功后最多持续六巡，玩家连续摸打，其他人不按通常轮次摸牌；期间和牌算一发。舍牌被鸣牌会提前结束效果，包括立直宣言牌被鸣牌。效果结束后本局进入过载，过载者放铳使对应和牌额外+2番，多家同时荣和分别加2番。

暗杠补牌也消耗魂之一击剩余巡数；若剩余巡数为0时暗杠，效果延至舍牌后才失效。不能仅用“已经摸了六次”抢先取消这张舍牌前的有效状态。连续暗杠等时序按实际动作检查，不承诺效果在任意非法杠链上延长。

## 16.9 万象修罗

采用修罗之战的交换、多人和牌、流局和不连庄流程，额外为每人配置一张百搭牌。本地用`bd`或`b`表示，它不能打出、不能吃碰杠、不能参与换三张。

百搭牌可代表除赤宝牌外任意一种牌，甚至作为已有四张同类牌之外的第五张；若所代表的牌是宝牌，照常计宝牌。通常“四张实体上限”不能直接否定这类活动解释，但实际非百搭的牌仍须满足牌组限制。

官方公开说明按最大和牌方式选择百搭牌的代表牌，不以里宝牌参与这一选择。确定代表后仍应按该手实际可用规则计分，不把“选择时不考虑里宝”误解成整局没有里宝。

本地编辑器选择时会考虑里宝；当候选代表牌的番数和符数都相同时，在这些等价候选中随机选择。该同分随机口径为2026-10-17用户补充确认。本页仅处理每人一张百搭，不能推广到多张百搭或把它作为普通赤牌。

## 16.10 背水之战与下克上

| 背水立直等级 | 费用 | 普通立直番数 | 双立直番数 |
|---|---|---|---|
| 通常 | 1000 | 1 | 2 |
| 真 | 5000 | 3 | 4 |
| 极 | 10000 | 5 | 6 |

强化须先满足立直条件；更高费用换取额外2／4番，不把5000点误写成“共5番”。费用与供托另记，额外番仍走通常等级上限。识别字段为 `beishuizhizhan_mode`，本地动作等级0／1／2对应通常／真／极。

下克上按和牌者实际现有点数确定倍率：至少30000为1倍，20000至不足30000为2倍，10000至不足20000为3倍，不足10000为4倍。本场、不听罚符与流局满贯不乘倍率，立直支付可能使玩家跨档。

例如立直前30000，支付1000后为29000，之后和牌按2倍档检查；若正常计算的和牌支付总额为8000、两本场，则四麻本场600另加，不能把8600整笔翻倍。多家荣和时，每位和牌家分别按自己和牌时的点数确定倍率；不能用同一时刻的公共点数快照替代逐家判定。
