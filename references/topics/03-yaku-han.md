# 3. 役种（Yaku）与番数（Han）

> 默认适用雀魂四人麻将段位场。必须至少具备一个役才能和牌；表宝、里宝、赤宝牌只增加番数。`门清`为未吃、碰、明杠或加杠的状态；暗杠不破门清。

雀魂的可选古役不属于本页段位役表。明确启用古役时，另读 [雀魂古役](14-guyi.md)，核对额外役种、门清限制及替换关系；其他地方古役或一番街扩展不能直接套用。

## 3.1 一番役

|   役种   |          成立条件          |  备注  |
|:------:|:----------------------:|:----:|
|   立直   | 门前清状态下听牌即可立直, 立直状态下和牌  | 门清限定 |
|   一发   |   立直后, 无人鸣牌的状态下一巡内和牌   | 门清限定 |
|   抢杠   | 别家加杠时荣和；雀魂规则下国士无双可抢暗杠  |      |
|  岭上开花  |      用摸到的岭上牌自摸和牌       |      |
|  海底摸月  | 最后一张通常摸牌自摸和牌       | 与岭上开花互斥 |
|  河底捞鱼  |        最后一张牌荣和         |      |
| 门前清自摸和 |       门前清状态下自摸和牌       | 门清限定 |
|   平和   |  四组顺子、非役牌雀头、最后为顺子两面听   | 门清限定 |
|  一杯口   |       两组完全相同的顺子        | 门清限定 |
| 役牌 三元牌 |        包含三元牌刻子         |      |
| 役牌 门风牌 |         包含自风刻子         |      |
| 役牌 场风牌 |         包含场风刻子         |      |
|  断幺九   |        手牌不含幺九牌         | 段位场允许副露 |

## 3.2 二番役

| 役种    | 成立条件                       |  备注   |
|-------|----------------------------|:-----:|
| 双立直   | 自己第一张舍牌前无人鸣牌，并在该次舍牌宣告立直    | 门清限定  |
| 七对子   | 七个不同的对子                    | 门清限定  |
| 混全带幺九 | 每组面子及雀头均含幺九牌，且至少含字牌和一组顺子   | 副露减1番 |
| 一气通贯  | 同种数牌组成123、456、789的顺子       | 副露减1番 |
| 三色同顺  | 万, 筒, 索都有相同数字的顺子           | 副露减1番 |
| 三色同刻  | 万, 筒, 索都有相同数字的刻子           |       |
| 三杠子   | 自己开杠三次                     |       |
| 对对和   | 四组面子全为刻子                   |       |
| 三暗刻   | 拥有三组暗刻；荣和牌组成的刻子不算暗刻        |       |
| 小三元   | 两组三元牌刻子/杠子，另一种为雀头；另与对应役牌复合 |       |
| 混老头   | 仅使用幺九牌, 且包含字牌              |       |

## 3.3 三番役

| 役种    | 成立条件                         |  备注   |
|-------|------------------------------|:-----:|
| 二杯口   | 包含两个一杯口；不会与七对子复合             | 门清限定  |
| 纯全带幺九 | 每组面子及雀头均含数牌幺九，不含字牌, 且至少有一组顺子 | 副露减1番 |
| 混一色   | 只包含一种数牌, 且含有字牌的刻子或雀头         | 副露减1番 |

## 3.4 六番役

| 役种  | 成立条件         |  备注   |
|-----|--------------|:-----:|
| 清一色 | 只包含一种数牌，不含字牌 | 副露减1番 |

## 3.5 役满

### 单倍役满

| 役种   | 成立条件                         | 备注                |
|------|------------------------------|-------------------|
| 天和   | 庄家起手配牌14张为和牌状态               |
| 地和   | 轮到自己之前无人鸣牌状态下第一巡自摸和牌         |
| 大三元  | 包含白、发、中的三组刻子                 | 有包牌规则             |
| 四暗刻  | 四组暗刻                         | 单骑听为双倍役满               |
| 字一色  | 只包含字牌                        |
| 绿一色  | 只包含索子23468以及发                | 发不是必需             |
| 清老头  | 只包含老头牌                       |
| 国士无双 | 全部十三种幺九牌各一张外加其中一种再有一张        | 十三面听为双倍役满              |
| 小四喜  | 包含三组风牌刻子外加剩下一种风牌雀头           |
| 四杠子  | 自己开杠四次                       | 是四杠散了的例外          |
| 九莲宝灯 | 同种数牌`1112345678999`加其中一种再有一张 | 九面听为双倍役满                 |

### 双倍役满

| 役种      | 成立条件          | 备注         |
|---------|---------------|------------|
| 纯正九莲宝灯  | 九莲宝灯最后9面听牌和牌  | 九莲宝灯的上位    |
| 四暗刻单骑   | 四暗刻最终单骑听牌和牌   | 四暗刻的上位     |
| 国士无双十三面 | 国士无双最后13面听牌和牌 | 国士无双的上位 |
| 大四喜     | 包含四种风牌的刻子     | 有包牌规则      |

### 天和的上位役满判定

雀魂段位场中，天和配牌同时满足四暗刻、国士无双或九莲宝灯的牌型条件时，分别按**四暗刻单骑、国士无双十三面、纯正九莲宝灯**计入，并与天和复合；不通过指定某一张配牌为和牌张，将它们降为下位形式。上位役满替代其下位役满，不重复相加。

这条首配牌规则不自动推广到地和；地和仍根据实际和牌张和等待形判定上位形式。房间关闭双倍役满时，倍数另按对应设置处理。此处采用 [2026-10-18用户确认](../evidence/user-confirmations-2026-10-18.md)，不将其描述为本次助手完成的服务器实测。

## 3.6 复合与排斥

- 七对子不与二杯口复合；平和不与对对和、七对子复合。
- 混一色可与役牌、混全带幺九、混老头等复合；清一色不与混一色复合。
- 小三元与两种三元牌役牌复合；大三元不再另计三元牌役。
- 混老头必须与对对和、七对子或相关役满等其他役复合。
- 累积役满固定为单倍役满，不与自然役满复合；多个自然役满按役满倍数累计。双倍役满变体见 [规则基线](../rules-sources.md)。
