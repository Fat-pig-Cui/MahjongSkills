# 13. 三人麻将（Sanma）规则差异

> 本章默认适用**雀魂三人麻将段位场**；友人房“无自摸损”仅在明确标注的对照部分适用。四人麻将仍以本目录第1至12章为默认体系。本章主要讲三麻与四麻不同之处；共通规则直接链接对应章节。所有平台专属结论的状态见 [三麻证据索引](../sanma-rules-sources.md)。

## 13.1 差异总览

| 项目 | 四人麻将默认 | 三人麻将差异 |
|---|---|---|
| 玩家与座次 | 东、南、西、北四家 | 东、南、西三家，北家座位空缺 |
| 牌组 | 136张，三门数牌完整 | 108张，万子只保留1万、9万；移除2至8万与红5万 |
| 红宝牌 | 红5万、红5筒、红5索各一张 | 红5筒、红5索各一张；不存在红5万 |
| 北牌 | 普通风牌 | 可作为拔北牌处理，具体时序见13.3 |
| 万子宝牌循环 | 1→2→…→9→1 | 1万与9万相互循环 |
| 原点／返点 | 25000／30000 | 35000／40000；两者返点均为原点加5000 |
| 吃与岭上牌 | 可以吃，4张岭上牌 | 禁止吃，8张岭上牌 |
| 自摸 | 其余三家支付 | 有自摸损，只收实际另外两家的支付 |
| 本场总额 | 每本300点 | 每本200点；自摸每名实际对手每本各付100点 |
| 荒牌罚符总额 | 3000点 | 2000点；全员听牌或全员未听牌均不收付 |
| 常规最后局／延长最后局 | 东风东4／南4、半庄南4／西4 | 东风东3／南3、半庄南3／西3；终局算法与普通流局推进由用户确认 |

<a id="sanma-tiles"></a>
## 13.2 牌组与和牌型

- 三麻使用108张牌：万子仅有1万、9万各4张；红5筒与红5索各一张；不存在红5万。筒子、索子与字牌的其余牌张数量与四麻相同。
- 因不存在万子2至8，万子不能组成顺子；`19m`只能用于对子、刻子、杠子或国士无双等牌型。
- 一般和牌型仍是“四组面子加一组雀头”；七对子、国士无双仍是特殊和牌型。详见 [基本构成](01-basic-composition.md)。
- 立直、振听、门清、荣和与自摸的基本定义沿用 [游戏流程](02-game-flow.md)。普通流局推进及本场变化与四麻同理，但三麻支付金额、人数与流局满贯自摸损按本章调整。

<a id="north"></a>
## 13.3 三家座次与拔北

- 三家按东、南、西就座，行动顺序、上家和下家的关系应按三家循环理解；不要将四麻的对家、四家立直或四风连打直接套入三麻。
- 三麻禁止吃。
- **拔北**：把手牌中的北单独取出作为拔北牌，等待抢北响应；无人和牌才从岭上补一张。补牌自摸可计岭上开花，三麻有8张岭上牌。
- 北拔不破门清，但会中断一发，并破坏地和、双立直、九种九牌所需的无鸣牌首巡条件。
- 他家拔北时可抢北荣和；响应在北被拔出后、拔北者岭上摸牌前，有人荣和则不摸补牌。抢北本身不是役，仍需另有役并满足非振听条件，不能自动计“抢杠”役。
- 立直后拔北只能使用刚摸到的北，不能拔此前已在手牌中的北；立直后暗杠必须包含刚摸的牌，并保持听牌种类不变。抢杠／抢北均在牌宣告杠／拔出后、岭上摸牌前响应。
- 通常牌山仅剩最后一张时，不可暗杠、加杠、大明杠或拔北。三麻段位场的杠宝牌时序沿用 [鸣牌与杠](09-call-kan-rules.md)。

## 13.4 役种与宝牌

<a id="sanma-yaku"></a>
### 共通与变化

- 共通役种、门清限制与符番定义见 [役种](03-yaku-han.md)；三麻中仍须满足“至少一个役”才能和牌，宝牌不能单独构成役。
- 因万子无法组成顺子，三色同顺不能成立；一气通贯与清一色仍可在筒子或索子中成立，不能将“没有万子顺子”误写为这些役整体不可用。
- 断幺九在三麻中不使用万子2至8；混一色、清一色、对对和、七对子和国士无双的相对出现频率会随牌组改变，但役的成立条件本身不能随意改写。
- 累积役满、自然役满复合与切上满贯规则直接沿用 [四麻役种](03-yaku-han.md) 和 [计分](04-scoring.md#base-scoring)；只有支付按三麻人数与自摸损调整。

<a id="north-dora"></a>
### 宝牌与北拔

- 红宝牌只有红5筒、红5索；不存在红5万。
- 万子指示牌的宝牌循环为：1万指示9万，9万指示1万。其他数牌、风牌和三元牌循环沿用 [特殊规则](05-special-rules.md)。
- 拔出的北基础每张计1番拔北宝牌，门清与副露相同；宝牌不能独立构成和牌所需的役。留在手牌中的北不计拔北宝牌。
- 北在面子中作客风，北刻子本身不构成役牌；北仍可用于对子、刻子、杠子、国士无双或字一色等牌型。
- 北无论留在手牌中还是拔出，都在表宝、里宝的计番范围内；拔出的北可以叠加拔北宝牌、表宝和里宝。每张对应指示牌分别计1番，同一北可对应多张指示牌；里宝仍须立直和牌。留在手牌中的北只计适用的表里宝，不计拔北宝牌。
- 三麻段位场允许副露断幺九。

## 13.5 计分、流局与赛制

- 原点35000、返点40000。东风使用东3／南3、半庄使用南3／西3作为常规／延长最后局；其余直接传入 [共通终局算法](08-match-rules.md#match-end)，本章不复制算法。同点按整场起家东、南、西；无人和牌终局供托按 [共通排名规则](08-match-rules.md#ranking) 分配。
- 符与基本点公式可参考 [计分](04-scoring.md)。三麻段位场采用**自摸损**：自摸和已成立的流局满贯均先按四麻标准计算另外三家的支付，再去掉不存在的北家支付，不转嫁给另外两家。荣和的普通手支付仍为子家基本点乘4、庄家乘6，向上取整到100点。
- 例如30符3番，基本点为960：子家自摸收庄家2000、另一子家1000，合计3000；庄家自摸收两家各2000，合计4000。以上均不含本场、供托与包牌。
- 包牌范围、触发和责任分摊沿用 [共通包牌规则](05-special-rules.md#pao)。三麻的差异仅在自摸金额：先按四麻自摸支付删去北家份额，再由责任者独自承担实际总额，不能把北家原本未支付的部分补回。
- 0本场、供托0根时，大三元自摸包牌部分为子家24000、庄家32000；大四喜按双倍役满，为子家48000、庄家64000，均由责任者独自支付。复合非包牌役满时分别计算后合并，具体推导与带本场案例见 [三麻包牌实例](../examples/scoring.md#complex-pao)。
- 荣和不扣自摸损；责任者与放铳者不同则各付包牌役满部分的一半，放铳者另付全部非包牌部分。例如子家荣和大三元，包牌总额仍为32000，两家各付16000，不能用自摸损后的24000分摊。
- 本场每本总额`(3-1)*100=200`点，n本为`200*n`点；荣和由放铳者支付，普通自摸由另外两家各支付`100*n`点。纯包牌自摸的责任者承担全部本场，复合非包牌役满的自摸仍由另外两家均摊，分支统一见 [包牌本场划分](05-special-rules.md#pao)。
- 多家荣和的本场及供托归属沿用 [共通计分规则](04-scoring.md#honba-deposits)，行动方向按三家东→南→西→东循环。
- 荒牌罚符总额`(3-1)*1000=2000`点，听牌方与未听牌方各自均分，具体如下；无人流局满贯时按此表结算。

| 听牌人数 | 每名听牌者获得 | 每名未听牌者支付 |
|---|---:|---:|
| 0或3 | 0 | 0 |
| 1 | 2000 | 1000 |
| 2 | 1000 | 2000 |

- 普通荒牌流局后的推进与四麻同理：庄家听牌则连庄，未听则流庄；不论是否连庄，本场加1，供托保留。以起家东、南、西三家的固定身份描述，东1／东2／东3依次由这三家坐庄；东3起家西家流庄且对局继续时进入南1，由起家东家坐庄。先按终局算法判断，若已经终局则不实际进入下一局。
- 途中流局沿用四麻共通条件及庄家连庄、本场加1、不结算荒牌罚符的处理；没有四风连打、四家立直，也不把它们改成三风连打、三家立直。九种九牌与四杠散了条件见 [规则边界](07-edge-cases.md)；不同玩家累计第四杠成立后不能继续开杠或拔北，完整顺序沿用共通优先级。
- 流局满贯成立条件沿用 [共通流局规则](02-game-flow.md#nagashi)。三麻区别是拔出的北单独放置，不属于牌河，不纳入这项判定。
- 单家流局满贯基本支付：子家收庄家4000、另一子家2000，共6000；庄家收另外两家各4000，共8000，不含本场与供托。多家成立时分别按满贯自摸计付并考虑自摸损；两家成立时，第三家分别承担对两家的满贯自摸支付，成立者之间等额支付抵消，示例见 [计分实例](../examples/scoring.md)。
- 流局满贯后的推进、本场、供托和不叠加听牌罚符均沿用 [共通后续流程](02-game-flow.md#nagashi)，仅支付按上文有自摸损的满贯计算。庄家成立但未听牌仍流庄，供托不会仅因流局满贯成立而发给成立者。
- 终局、第四杠与复杂包牌均已由用户报告完成实际验证，当前没有未闭环的规则验证项；完成记录与追溯材料说明统一见 [验证状态](../pending-verification.md)，确认来源及三麻适配见 [三麻证据索引](../sanma-rules-sources.md)。

### 友人房“无自摸损”（不作为段位场默认）

开启此选项后，四麻理论上北家应支付的点数由实际另外两家平摊均分，补入各自正常支付；自摸与流局满贯据此调整。例如0本场30符3番：子家自摸原收庄家2000、子家1000，补偿北家1000后改收2500、1500；庄家自摸原收两家各2000，补偿北家2000后改收两家各3000。详细对照见 [三麻计分实例](../examples/scoring.md)。

自然役满、多倍／复合役满和累积役满均使用相同无自摸损支付法：先按对应役满倍数算四麻理论自摸，再由实际两名对手均分北家份额。子家单倍役满自摸收庄家20000、另一子家12000，共32000；庄家收两家各24000，共48000。包牌部分也先按启用的自摸支付法求总额，再转由责任者支付；非包牌部分照常结算。本场分配不因无自摸损而改变。具体对照见 [无自摸损役满实例](../examples/scoring.md#no-loss-yakuman)。

## 13.6 向听、牌效率与攻守

- 向听的基本概念见 [向听与牌效率](10-shanten-efficiency.md)，但有效牌计算必须基于108张牌。万子中间张完全不存在，不能把四麻的万子顺子受入计入三麻。
- 缺少万子中张会减少普通顺子组合，字牌、对子、刻子和染手路线的相对价值上升；这不代表每一手都应强行对对和或染手，仍须比较向听、受入、役、宝牌和安全度。
- 红宝牌集中于筒子与索子；已拔出的北基础每张增加1番，留在手牌中的北不计拔北宝牌，两者均可计适用的表里宝。拔与不拔仍需比较牌型、打点与抢北风险。
- 防守的现物、筋、壁概念仍可参考 [防守与危险度](11-defense-danger.md)，但三家对局的可见信息、剩余牌和副露比例不同，不能直接套用四麻的风险直觉或支付损失。
- All Last 的顺位判断仍遵循“速度、打点、风险、顺位”四因素，须按本章13.5的40000返点、负点飞人及终局条件判断，见 [攻守与终局策略](12-strategy-placement.md)。
