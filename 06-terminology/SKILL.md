# 6. 常用术语速查

| 术语（日文/中文） | 含义 |
|-----------------|------|
| ツモ（Tsumo） | 自摸 |
| ロン（Ron） | 荣和（点炮） |
| リーチ（Riichi） | 立直 |
| ポン（Pon） | 碰 |
| チー（Chi） | 吃 |
| カン（Kan） | 杠 |
| フリテン（Furiten） | 振听 |
| テンパイ（Tenpai） | 听牌 |
| ノーテン（Noten） | 未听牌 |
| オーラス（Oorasu） | 最终局（All Last） |
| 連荘（Renchou） | 连庄 |
| 親（Oya） | 庄家（亲家） |
| 子（Ko） | 闲家（子家） |
| 供託（Kyoutaku） | 立直棒/场棒 |
| 流局（Ryukyoku） | 流局 |
| 牌山（Haiyama） | 牌山（牌堆） |
| 河（Kawa） | 牌河（打出的牌） |
| 手牌（Tehai） | 手中持有的牌 |
| 副露（Furo） | 鸣牌（吃碰杠）后的亮牌 |

| 槍槓（Chankan） | 抢杠 |
