# 6. 常用术语速查

| 术语（日文/中文）             | 含义                          |
|-----------------------|-----------------------------|
| ツモ（Tsumo）             | 自摸                          |
| ロン（Ron）               | 荣和；由放铳者支付的和牌                |
| リーチ（Riichi）           | 立直；门清听牌时支付1000点的宣言          |
| ダブルリーチ（Double Riichi） | 双立直；无人鸣牌前的第一轮舍牌即立直          |
| ポン（Pon）               | 碰                           |
| チー（Chi）               | 吃；仅能取得上家的舍牌组成顺子             |
| カン（Kan）               | 杠，包含大明杠、暗杠、加杠               |
| フリテン（Furiten）         | 振听；限制荣和、不限制自摸               |
| テンパイ（Tenpai）          | 听牌                          |
| シャンテン数                | 向听数；距离听牌所需的最少进张数            |
| ノーテン（Noten）           | 未听牌                         |
| オーラス（Oorasu）          | 最终局（All Last）               |
| 連荘（Renchou）           | 连庄                          |
| 親（Oya）                | 庄家（亲家）                      |
| 子（Ko）                 | 闲家（子家）                      |
| 供託（Kyoutaku）          | 供托，通常指桌面的立直棒                |
| 本場（Honba）             | 本场；连庄或流局后累加的场棒              |
| 流局（Ryukyoku）          | 流局，含荒牌流局与途中流局               |
| 牌山（Haiyama）           | 牌山（牌堆）                      |
| 王牌                    | 不参与通常摸牌的14张牌，含岭上牌与宝牌指示牌     |
| 河（Kawa）               | 牌河（已打出的舍牌）                  |
| 手牌（Tehai）             | 手中持有、尚未副露的牌                 |
| 副露（Furo）              | 吃、碰、明杠或加杠形成的亮牌面子            |
| 門清（Menzen）            | 无副露状态；暗杠不破门清                |
| 和了（Agari）             | 和牌                          |
| ドラ（Dora）              | 表宝牌                         |
| 裏ドラ（Ura Dora）         | 里宝牌，仅立直和牌时翻开                |
| 赤ドラ（Aka Dora）         | 赤宝牌（红五）                     |
| 槓ドラ                   | 杠后新增的表宝牌                    |
| 嶺上開花（Rinshan Kaihou）  | 杠后从岭上补牌自摸和牌                 |
| 槍槓（Chankan）           | 抢杠；对加杠牌荣和                   |
| 現物（Genbutsu）          | 对某玩家已打出过的牌；对其通常是绝对安全牌       |
| 筋（Suji）               | 用立直者舍牌推断两面听可能性的防守线索，不是绝对安全  |
| 壁（Kabe）               | 某种牌已见四张，从而降低相邻顺子可能性的牌张信息    |
| 頭跳（Atama Hane）        | 多家荣和时只让距离放铳者最近者和牌的房规；非本仓库默认 |
| 切り上げ満貫                | 切上满贯；将临界符番上调满贯的房规；非本仓库默认    |
| 飛び（Tobi）              | 点数降至0以下，牌局提前结束              |
| 返点                    | 用于最终排名结算的返还点设定              |
| 包（Pao）                | 责任支付，通常与特定役满的副露责任有关         |
