# 3. 役种（Yaku）与番数（Han）

> 默认适用雀魂四人麻将段位场。必须至少具备一个役才能和牌；表宝、里宝、赤宝牌只增加番数。`门清`为未吃、碰、明杠或加杠的状态；暗杠不破门清。

## 3.1 一番役

| 役种 | 门清/副露 | 成立条件 |
|---|---|---|
| 立直 | 门清 | 听牌时支付1000点宣言 |
| 一发 | 门清立直后 | 立直后至下一次自己摸牌前和牌，期间没有鸣牌或杠打断 |
| 门前清自摸和 | 门清 | 自摸和牌 |
| 断幺九 | 均可 | 仅用2至8的数牌；段位场允许副露断幺九 |
| 平和 | 门清 | 四组顺子、非役牌雀头、两面听 |
| 一杯口 | 门清 | 两组完全相同的顺子 |
| 役牌 | 均可 | 白、发、中、场风或自风的刻子/杠子；场风与自风重合时计两番 |
| 海底摸月 | 均可 | 摸取最后一张通常牌后自摸 |
| 河底捞鱼 | 均可 | 最后一张通常舍牌被荣和 |
| 岭上开花 | 均可 | 杠后补牌自摸和牌 |
| 抢杠 | 均可 | 他人加杠时荣和；国士无双可抢暗杠 |

## 3.2 二番役

| 役种 | 门清/副露 | 成立条件 |
|---|---|---|
| 双立直 | 门清 | 无人鸣牌前的第一轮舍牌即立直 |
| 七对子 | 门清 | 七个不同牌种的对子；固定25符 |
| 三色同顺 | 门清2番 / 副露1番 | 三门花色各有一组同数字顺子 |
| 一气通贯 | 门清2番 / 副露1番 | 同一花色同时有123、456、789 |
| 混全带幺九 | 门清2番 / 副露1番 | 每组面子及雀头均含幺九牌，且至少含字牌 |
| 对对和 | 均可 | 四组面子全为刻子或杠子 |
| 三暗刻 | 均可 | 三组暗刻或暗杠；荣和牌组成的刻子通常不算暗刻 |
| 三色同刻 | 均可 | 三门花色各有一组同数字刻子/杠子 |
| 三杠子 | 均可 | 自己拥有三组杠子 |
| 混老头 | 均可 | 仅用字牌和数牌幺九；必与其他役复合 |
| 小三元 | 均可 | 两组三元牌刻子/杠子，另一种为雀头；另与对应役牌复合 |

## 3.3 三番役

| 役种 | 门清/副露 | 成立条件 |
|---|---|---|
| 二杯口 | 门清 | 两组不同的一杯口；不与七对子复合 |
| 纯全带幺九 | 门清3番 / 副露2番 | 每组面子及雀头均含数牌幺九，不含字牌 |
| 混一色 | 门清3番 / 副露2番 | 一门数牌与字牌构成 |

## 3.4 六番役

| 役种 | 门清/副露 | 成立条件 |
|---|---|---|
| 清一色 | 门清6番 / 副露5番 | 只使用一门数牌，不含字牌 |

## 3.5 役满

| 役种 | 成立条件 | 备注 |
|---|---|---|
| 天和 | 庄家起手14张直接自摸和牌 | 役满 |
| 地和 | 闲家第一轮第一次摸牌自摸，期间无人鸣牌 | 役满 |
| 国士无双 | 十三种幺九牌各一张，另有其中一种重复 | 十三面听的双倍役满与否见规则基线 |
| 四暗刻 | 四组暗刻/暗杠 | 单骑听的双倍役满与否见规则基线；非单骑荣和通常不成立 |
| 大三元 | 白、发、中均为刻子/杠子 | 可能触发责任支付 |
| 小四喜 | 三组风牌刻子/杠子加另一种风牌雀头 | 役满 |
| 大四喜 | 四组风牌刻子/杠子 | 双倍役满与责任支付以段位场设定为准 |
| 字一色 | 全为字牌 | 役满 |
| 绿一色 | 仅用索子2、3、4、6、8与发 | 发不是必需 |
| 清老头 | 全为数牌幺九 | 役满 |
| 九莲宝灯 | 同一花色`1112345678999`加任意同花色一张 | 九面听双倍役满与否见规则基线 |
| 四杠子 | 自己拥有四组杠子并和牌 | 是四杠散了的例外 |

## 3.6 复合与排斥

- 七对子不与二杯口复合；平和不与对对和、七对子复合。
- 混一色可与役牌、混全带幺九、混老头等复合；清一色不与混一色复合。
- 小三元与两种三元牌役牌复合；大三元不再另计三元牌役。
- 混老头必须与对对和、七对子、混一色或相关役满等其他役复合。
- 役满不按普通番数与满贯级别合算；多个独立役满能否累计，以及双倍役满变体，见 [规则基线](../reference/rules-sources.md)。
