# 7. 注意事项（规则边界）

## 7.1 振听与见逃

| 条件                 | 结果              | 例外/解除             |
|--------------------|-----------------|-------------------|
| 牌河中有当前任一种荣和牌       | 舍张振听，不能荣和       | 改变听牌形且新听牌不含已舍牌时解除 |
| 非立直时放过可荣和牌         | 同巡振听，不能荣和       | 下一次自己舍牌后解除        |
| 立直后放过可荣和牌，或因振听不能荣和 | 立直后振听，至本局结束不能荣和 | 自摸始终可和            |

- “放过”包括主动不荣和, 无役无法和牌, 因自己处于振听而无法荣和。
- 振听只限制荣和，不影响自摸、听牌状态和立直本身。

## 7.2 立直后暗杠

- 立直后不得吃、碰、明杠或加杠。
- 立直后仅可对自己摸到的第四张相同牌暗杠，且暗杠前后听牌种类不得改变；面子构成是否变化不影响暗杠是否合法。
- 暗杠会中断其他立直者的一发；通过抢暗杠判定后立即翻新增宝牌指示牌，再摸岭上，完整时序见 [鸣牌与杠](../09-call-kan-rules/SKILL.md)。

## 7.3 途中流局条件

| 事件   | 条件                            | 结果                         |
|------|-------------------------------|----------------------------|
| 九种九牌 | 无鸣牌、第一巡自己的第一次摸牌后，持有九种或以上不同幺九牌 | 可自行宣告流局；不宣告可继续打            |
| 四风连打 | 四人第一张舍牌同为同一种风牌，且无人鸣牌          | 途中流局                       |
| 四家立直 | 四名玩家均成功立直                     | 途中流局；若第四家立直的宣言牌被荣和，和牌优先    |
| 四杠散了 | 第四个杠成立, 开第四杠后的该玩家的切牌未放铳后流局    | 通常途中流局；一人独自完成四杠并可能四杠子和牌是例外 |

## 7.4 和牌、抢杠与流局优先级

1. 舍牌出现后，荣和优先于吃、碰、明杠。
2. 加杠宣言后、杠者岭上摸牌前，其他玩家可抢杠荣和；国士无双可抢暗杠, 国士无双十三面理论上也可以但因为不存在第五张同样的牌, 所以遇不到。
3. 抢杠成立时不完成该次加杠，因此不触发岭上摸牌、杠宝牌或四杠散了。
4. 岭上开花在补牌后成立；若第四杠后的岭上牌让开杠者自摸和牌，则和牌优先于四杠散了。
5. 四杠散了在开第四杠玩家开第四杠后的切牌通过后流局；若切牌未通过(即放铳)也不会构成四杠散了。
6. 通常牌山仅剩最后一张时，暗杠、加杠与大明杠均不可宣告；最后一张通常舍牌可以河底荣和。

四麻段位场允许一炮三响：三家对同一舍牌荣和时按和牌分别结算，不触发“三家和了流局”。本场加点及全部供托归从放铳者开始逆时针遇到的第一位和牌者；各家的和牌资格不受这一归属规则影响。

## 7.5 易混淆的限制

- 鸣牌后面子固定，不能将已副露的牌重新拆组；但仍可用手牌重组未副露部分。
- 暗杠不破门清，明杠会破门清, 加杠因为之前需要碰, 所以也不会是门清状态。
- 双立直要求第一轮舍牌前无人鸣牌；任意鸣牌会使之后的首巡立直不再满足双立直。
- 天和、地和会被鸣牌或非规定的首巡动作中断。
