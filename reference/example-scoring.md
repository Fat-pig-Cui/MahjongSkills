# 点数计算实例

## 实例1：基础点数计算（子家·荣和）

```
手牌：1m 2m 3m  4p 5p 6p  2s 3s 4s  6z 6z  7z 7z
荣和：7z
役：立直(1番) + 役牌·中(1番) = 2番
符：底符20 + 雀头(中)2 = 22符 → 切上30符
```

**计算**：
- 基本点 = 30符 × 2^(2+2) = 30 × 16 = 480点
- 子家荣和支付：480 × 4 = 1920 → 切上 **2000点**

---

## 实例2：平和自摸（子家）

```
手牌：1m 2m 3m  4p 5p 6p  2s 3s 4s  5s 6s  7z 7z
自摸：7s
役：平和(1番) + 门清自摸(1番) = 2番
符：平和自摸固定20符
```

**计算**：
- 基本点 = 20符 × 2^(2+2) = 20 × 16 = 320点
- 亲家支付：320 × 2 = 640 → 切上 700点
- 子家各支付：320 × 1 = 320 → 切上 400点（×2家）
- 总计：700 + 400 + 400 = **1500点**

## 实例4：跳满判定

```
手牌：1m 1m 1m  2m 3m 4m  5m 6m 7m  8m 9m  5z 5z 5z
自摸：7m
役：清一色(6番) = 跳满
```

**计算**：
- 子家跳满：**12000点**
- 亲家支付：6000点
- 子家各支付：3000点

## 实例5：符数计算细节

```
手牌：1z 1z 1z(暗刻)  2z 2z(雀头)  3m 4m 5m  6p 7p 8p
      1s 2s 3s  7z 7z
荣和：7z
役：役牌·中(1番)
```

**符数明细**：
| 来源 | 符数 |
|------|------|
| 底符 | 20符 |
| 1z暗刻（幺九牌） | 8符 |
| 雀头2z（非役牌） | 0符 |
| 荣和（边张听） | 2符 |
| **合计** | 30符 |

**计算**：
- 基本点 = 30符 × 2^(1+2) = 30 × 8 = 240点
- 子家荣和支付：240 × 4 = 960 → 切上 **1000点**
