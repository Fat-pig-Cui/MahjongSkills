# 雀魂三人麻将段位规则基线与来源

## 适用范围

本文件与 [三人麻将差异 SKILL](../13-sanma/SKILL.md) 仅讨论**雀魂三人麻将段位场**。它不覆盖雀魂四人麻将段位场，也不直接代表比赛房、自定义房或其他平台的三麻设定。

四人麻将规则请见 [四麻规则基线](rules-sources.md)。三麻与四麻共通的定义（和牌型、立直、振听、符的构成等）可引用四麻章节；涉及人数、牌组、北拔、宝牌、支付、流局或终局时，必须以本文件为准。

## 来源与维护原则

核验优先顺序：

1. 雀魂客户端三人麻将段位场的规则、结算和房间说明。
2. 雀魂官方网站、公告或帮助中心的三人麻将说明。
3. 本仓库三麻章节与示例。

每次客户端规则变动时，先更新本文件，再更新 `13-sanma/SKILL.md` 和相关示例。未核验项目不得伪装为固定平台规则。

## 已核验的基础差异

| 项目 | 状态 | 本仓库采用结论 |
|---|---|---|
| 玩家数 | 已核验 | 东、南、西三家对局；北家座位空缺 |
| 牌组 | 已核验 | 共108张：移除万子2至8；万子只保留1万与9万；没有红5万 |
| 红宝牌 | 已核验 | 红5筒与红5索各一张；不存在红5万 |
| 北拔 | 已核验 | 北牌可作为三麻专属的拔北牌处理，详细流程与宝牌价值见三麻章节 |
| 基本和牌形与振听 | 已核验 | 与四麻共通：一般型、七对子、国士无双，以及立直、振听等基本定义仍适用 |
| 万子宝牌循环 | 已核验 | 万子指示牌在1万与9万之间循环：1万指示9万，9万指示1万 |

## 平台差异警告

三麻在北拔、北牌是否保留役牌属性、赤牌枚数、数え役满、切上满贯、自摸支付和终局条件上常有平台差异。除本文件标为“已核验”的内容外，实战以雀魂客户端当前规则与结算结果为准。
