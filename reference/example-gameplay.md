# 游戏流程示例

## 场景设定

- 东1局，庄家（亲）为玩家A
- 玩家A（亲）、B（子·西）、C（子·南）、D（子·北）
- 顺序：A → B → C → D（逆时针）

---

## 配牌

**玩家A（亲·14张）**：
```
1m 2m 3m  5p 6p 7p  9s 9s  1z 1z  4m 5m 7z 7z
```

**玩家B（子·13张）**：
```
2p 3p 4p  3s 4s 5s  6m 7m 8m  2z 2z  6z 6z 6z
```

---

## 东1局进行

### 第1巡
- A打4m
- B摸牌(8s)，打8s
- C摸牌，打1p
- D摸牌，打南(2z)

### 第3巡
- B摸牌后手牌成形：
  ```
  2p 3p 4p  3s 4s 5s  6m 7m 8m  2z 2z  6z 6z 6z
  ```
  听牌：2z（南）单骑

### 第4巡
- A打出2z（南）
- B宣言「ロン（Ron）！」

---

## 结算

**B的手牌**：
```
2p 3p 4p  3s 4s 5s  6m 7m 8m  [2z 2z 2z]  6z 6z
```

- **役**：役牌·南(1番) + 役牌·发(1番) = 2番
- **符**：底符20 + 南暗刻8 + 发暗刻8 + 单骑听2 = 38 → 切上40符
- 基本点 = 40 × 2^4 = 640
- 亲(A)支付：640 × 4 = 2560 → 切上 **2600点**

---

## 鸣牌示例：碰（Pon）

```
C的手牌：5z 5z 6m 7m 8m 2p 3p ...
```
D打出5z（白）→ C宣言「ポン（Pon）！」
```
C的副露显示：[5z 5z 5z]（横置一张表示来源）
```
副露后C不再是门清状态。

---

## 立直示例

```
D的手牌（门清·听牌）：
1m 2m 3m  4p 5p 6p  2s 3s 4s  6z 6z  7s 8s
听牌：6s 或 9s
```
1. D宣言「リーチ（Riichi）」，支付1000点立直棒
2. D打出一张非听牌的牌（横置表示宣言牌）
3. 之后D不得更换手牌，摸到什么打什么（除非摸到和牌牌或可暗杠的牌）

---

## 流局示例：四风连打

- 第1巡：A、B、C、D依次打出同一风牌（如东1z）
- 条件满足 → 流局
- 若庄家（A）听牌则连庄，否则轮庄至B

---

## 本场累加示例

- 东1局：本场0
- 庄家A连庄 → 东1局1本场
- 再次连庄 → 东1局2本场
- 本场费每本场300点，由和牌者额外收取
