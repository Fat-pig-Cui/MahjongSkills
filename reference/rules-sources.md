# 雀魂段位规则基线与来源

## 适用范围

本仓库正文默认讨论**雀魂四人麻将段位场**。三人麻将、比赛房、自定义房和其他平台的规则，只有在明确标注时才适用；未标注时不得以其覆盖段位场规则。

本文件记录四人麻将段位场的结论。三人麻将请单独参阅 [三麻规则基线](sanma-rules-sources.md) 与 [三人麻将规则差异](../13-sanma/SKILL.md)。

## 主要核验来源

规则更新时按以下顺序核对：

1. 雀魂客户端内的四人麻将段位场规则与结算说明。
2. 雀魂官方网站、公告或帮助中心发布的四人麻将规则说明。
3. 本仓库各章节；若其与前两项冲突，以雀魂最新公开说明为准，并同步修订本文件。

> 本文件记录的是文档采用的结论，不替代客户端实际生效的规则。游戏版本或活动规则变更时，应重新核验。

## 段位场采用结论

本仓库采用下列四麻段位场结论。2026-10-07用户确认原点、返点、多人荣和、一炮三响、终局算法、供托归属、同点排名、杠宝牌与抢杠时序、本场及荒牌罚符；公开来源和核验边界见 [本次核验记录](verification-2026-10-07.md)。用户确认结论尚未作服务器实测；四杠散了的完整优先级与包牌边界仍待交叉核验。

| 项目   | 本仓库采用                             | 写作要求                                   |
|------|-----------------------------------|----------------------------------------|
| 默认玩法 | 四人麻将、红5万／筒／索各一张、开放断幺九 | 三麻内容须显式标注“仅三麻” |
| 原点与返点 | 原点25000、返点30000；返点为原点加5000 | 用户确认，官方公开配置一致 |
| 四人南终局 | 南4起每局结算后：负点飞人；当局庄家第一且达到30000；南4流庄且有人达到30000；西4流庄，任一成立即终局 | 用户确认；西场非庄家达到返点不独立触发终局，完整伪代码见第8章 |
| 四人东终局 | 同一算法：常规最后局改为东4，延长最后局改为南4，返点仍为30000；南4流庄直接终局 | 用户确认；南场非庄家达到返点不独立触发终局 |
| 役与宝牌 | 必须至少有一个役；表宝、里宝、赤宝只加番，不构成役         | 不得以纯宝牌和牌                               |
| 多家荣和 | 允许双响与一炮三响；三家荣和时分别结算和牌，不流局 | 和牌资格不采用头跳；供托、本场分配须另行说明 |
| 切上满贯 | 默认不采用切上满贯                         | 4番30符、3番60符仍按通常计算，不直接升满贯               |
| 累积役满 | 13番及以上按累积役满处理 | 固定单倍役满；即使26番或更高也不加倍，且不与自然役满复合 |
| 本场   | 荣和由放铳者额外支付每本300点；多家荣和时仅逆时针遇到的第一位和牌者取得本场加点；自摸由三家各额外支付每本100点 | 多家归属由用户确认；本场不按和牌人数重复收取，见 [计分](../04-scoring/SKILL.md) |
| 荒牌罚符 | 听牌者合计收取3000点，未听牌者合计支付3000点        | 见 [流程](../02-game-flow/SKILL.md)       |
| 立直棒  | 每根1000点；多家荣和时全部供托归从放铳者开始逆时针遇到的第一位和牌者；流局继续时保留，无人和牌终局时归顺位1 | 用户确认；归属见 [赛制](../08-match-rules/SKILL.md) |
| 排名与同点 | 先按结算后点数从高到低排名；同点按整场开局时东、南、西、北的顺序，东优先、北最后 | 用户确认；起家座次固定，不使用当前小局的座风 |
| 责任支付 | 仅大三元、大四喜适用包牌 | 由完成该役满的最后一次碰或大明杠触发；支付见 [特殊规则](../05-special-rules/SKILL.md) |
| 末张限制 | 通常牌山仅剩最后一张时不可暗杠、加杠或大明杠 | 最后通常摸牌自摸计海底摸月；最后岭上补牌自摸计岭上开花 |
| 途中流局 | 四风连打、四家立直、九种九牌、四杠散了按段位场规则处理       | 见 [边界](../07-edge-cases/SKILL.md)      |
| 流局满贯成立 | 荒牌流局时，自己的舍张全为幺九牌且没有被他家吃、碰、杠 | 官方公开配置`fandesc.fandesc` id 501；三麻同条件，拔北不算舍张（用户确认） |
| 流局满贯流程 | 点数按满贯自摸计算，其他按荒牌流局处理：庄家听牌连庄、未听流庄，本场加1，供托保留；不再叠加听牌罚符 | 用户确认共通流程；终局时供托归第一名，三麻支付考虑自摸损 |
| 无人和牌终局的供托 | 全部供托归结算顺位为1的玩家；同点按起家座次判定第一名 | 用户确认；见 [赛制](../08-match-rules/SKILL.md) |
| 杠宝牌时序 | 暗杠通过抢杠判定后先翻指示牌，再摸岭上；大明杠／加杠在岭上摸牌后的下一步非和牌操作后翻指示牌 | 用户确认；明杠／加杠本次岭上和牌不计尚未翻开的新杠宝牌；比赛房自定义须单独标注 |
| 抢杠与立直后暗杠 | 抢杠响应在杠牌宣告后、岭上摸牌前；立直后暗杠必须使用刚摸到的牌，且听牌种类不变 | 用户确认时序与刚摸牌限制；国士抢暗杠条件见第9章 |

## 常见平台差异

| 规则    | 段位场文档口径          | 常见差异                             |
|-------|------------------|----------------------------------|
| 和牌头跳 | 段位场不采用；多家都可荣和，本场和供托仅归逆时针第一位和牌者 | 其他房规可能只允许距离放铳者最近者荣和 |
| 切上满贯  | 不采用              | 部分平台将4番30符、3番60符切上满贯             |
| 双倍役满  | 纯正九莲宝灯、四暗刻单骑、国士无双十三面按双倍役满结算 | 其他役满变体须明确标注平台差异 |
| 西入/延长 | 由段位场终局设定决定       | 比赛房或自定义房可不同                      |
| 包牌    | 仅限客户端明确支持的役满责任支付 | 触发条件与分摊方式常因平台不同                  |
