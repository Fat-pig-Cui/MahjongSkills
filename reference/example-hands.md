# 和牌牌例示范

以下用简写：`m`=万、`p`=筒、`s`=索、`z`=字（1东、2南、3西、4北、5白、6发、7中）。`[]`表示副露；示例默认其余役牌条件均不额外成立。

## 一番役

### 平和（Pinfu）

```
123m 456p 234s 567s 77z，听4s或7s
```

全部顺子，雀头7z不是役牌，且为两面听。门清限定。

### 断幺九（Tanyao）

```
234m 345p 567s [456s] 66p
```

没有1、9或字牌。雀魂段位场允许副露断幺九。

### 一杯口（Iipeikou）

```
123m 123m 456p 567s 88p
```

两组相同顺子，门清限定。

### 役牌（Yakuhai）

```
111z 234m 567p 678s 55p
```

若1z为场风或自风，计一番；白、发、中刻子也各计一番。

### 岭上开花与抢杠

```
岭上开花：暗杠后从岭上摸到和牌张自摸。
抢杠：他人加杠的第四张牌正好是自己的荣和牌。
```

两者都可与其他役复合，但不能彼此复合。

## 二番役

### 七对子（Chiitoitsu）

```
11m 22m 33p 44p 55s 66s 77z
```

七个不同牌种的对子，门清限定，固定25符。

### 三色同顺（Sanshoku Doujun）

```
234m 234p 234s 567s 55z
```

门清2番，副露1番。

### 一气通贯（Ittsu）

```
123m 456m 789m 234p 55z
```

门清2番，副露1番。

### 混全带幺九（Chanta）

```
123m 789p 111z 789s 99m
```

每个面子和雀头都含幺九，且至少含字牌；门清2番，副露1番。

### 小三元（Shousangen）

```
555z 666z 77z 234m 678p
```

小三元2番，另有白和发的两番役牌，合计至少4番。

## 三番与六番役

### 二杯口（Ryanpeikou）

```
123m 123m 456p 456p 77s
```

两组成对的相同顺子，门清3番；不与七对子复合。

### 纯全带幺九（Junchan）

```
123m 789p 123s 789s 99m
```

全部面子和雀头都含数牌幺九，不含字牌；门清3番，副露2番。

### 混一色与清一色

```
混一色：123m 456m 789m 111z 55z
清一色：123m 456m 789m 345m 66m
```

混一色门清3番/副露2番；清一色门清6番/副露5番。

## 役满

### 国士无双

```
1m 9m 1p 9p 1s 9s 1z 2z 3z 4z 5z 6z 7z + 任一幺九牌
```

十三种幺九牌各一张，再有其中一种成对。

### 四暗刻

```
222m 555p 888s 111z 77m，听7m单骑
```

四组必须均为暗刻或暗杠；单骑听与双倍役满采用与否见规则基线。

### 大三元与大四喜

```
大三元：555z 666z 777z 234m 88p
大四喜：111z 222z 333z 444z 55m
```

这两类役满可能涉及责任支付，必须按雀魂客户端规则核验。

### 九莲宝灯与四杠子

```
九莲宝灯：1112345678999m + 任意m
四杠子：同一玩家拥有四组杠子并和牌
```

四杠子是四杠散了的例外条件之一。
