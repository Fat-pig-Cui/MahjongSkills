# 和牌牌例示范

以下牌例用简写表示：`m`=万, `p`=筒, `s`=索, `z`=字牌（1东2南3西4北5白6发7中）。
`[]`表示副露（鸣牌）。

---

## 一番役

### 立直（Riichi）
```
手牌：1m 2m 3m  4p 5p 6p  2s 3s 4s  6z 6z  7z 7z
听牌：7z
说明：门清状态，听7z（中），宣言立直
```

### 平和（Pinfu）
```
手牌：1m 2m 3m  4p 5p 6p  2s 3s 4s  5s 6s  7z 7z
听牌：4s 或 7s（两面听）
条件：全部顺子，雀头7z非役牌（假设场风/自风非7z）
```

### 断幺九（Tanyao）
```
手牌：2m 3m 4m  3p 4p 5p  5s 6s 7s  4m 4m  6p 6p
说明：无1、9、字牌，全部为中张牌（2-8）
```

### 役牌 — 场风/自风/三元牌
```
手牌：1z 1z 1z  2m 3m 4m  5p 6p 7p  3s 3s  8s 8s
役：东(1z)的刻子，若场风或自风为东，则计一番
```

### 一杯口（Iipeikou）
```
手牌：1m 1m 2m 2m 3m 3m  4p 5p 6p  5s 6s 7s  8p 8p
说明：万子有两组相同的顺子(123m, 123m)，门清限定
```

## 二番役

### 三色同顺（Sanshoku Doujun）
```
手牌：2m 3m 4m  2p 3p 4p  2s 3s 4s  5z 5z  7s 8s
听牌：6s 或 9s
说明：万、筒、索三色各有一组234顺子
```

### 一气通贯（Ikkitsuukan）
```
手牌：1m 2m 3m  4m 5m 6m  7m 8m 9m  3p 3p  4z 4z
说明：同一花色（万子）含123、456、789三组顺子
```

### 对对胡（Toitoi）
```
手牌：2m 2m 2m  5p 5p 5p  8s 8s 8s  3z 3z 3z  1z 1z
说明：全部为刻子，无顺子
```

### 三暗刻（San Ankou）
```
手牌：3m 3m 3m  6p 6p 6p  9s 9s 9s  2m 3m 4m  5z 5z
说明：三个暗刻（未鸣牌的刻子）
```

---

## 三番役

### 混一色（Honitsu）
```
手牌：1m 2m 3m  4m 5m 6m  7m 8m 9m  1z 1z 1z  5z 5z
说明：仅由万子 + 字牌构成
```

---

## 六番役

### 清一色（Chinitsu）
```
手牌：1m 1m 2m 3m 4m 5m 6m 7m 8m 9m 9m  3m 4m
听牌：2m 或 5m
说明：全部为万子，无其他花色、无字牌
```

---

## 役满

### 国士无双（Kokushi Musou）
```
手牌：1m 9m 1p 9p 1s 9s 1z 2z 3z 4z 5z 6z 7z + 任意幺九牌一张
听牌：13面听（缺哪张听哪张）
```

### 大三元（Daisangen）
```
手牌：5z 5z 5z  6z 6z 6z  7z 7z 7z  2m 3m 4m  3p 3p
说明：白、发、中三种三元牌均为刻子
```

### 四暗刻（Suuankou）
```
手牌：2m 2m 2m  5p 5p 5p  8s 8s 8s  4z 4z 4z  1m 1m
说明：全部为暗刻，听1m单骑
```

### 九莲宝灯（Chuuren Poutou）
```
手牌：1m 1m 1m 2m 3m 4m 5m 6m 7m 8m 9m 9m 9m + 任意万子一张
听牌：九面听（1m~9m任意一张均能和牌）
```
