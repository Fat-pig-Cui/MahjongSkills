# 立直麻将（Riichi Mahjong）核心规则与术语参考手册

---

## 1. 游戏目标与基本构成

### 1.1 游戏目标
- 通过摸牌、打牌，尽快将自己手中的牌组合成符合特定牌型的“和牌”形态。
- 和牌时，根据牌型难度和附加符数计算得分，最终以点数高低排名。

### 1.2 牌种与数量
- **总牌数**：136张（不含花牌）。
- **牌种分类**：
  - **数牌（1-9）**：分为三组：
    - 万子（m）：1万～9万，各4张。
    - 筒子（p）：1筒～9筒，各4张。
    - 索子（s）：1索～9索，各4张。
  - **字牌**：分为两组：
    - 风牌：东（1z）、南（2z）、西（3z）、北（4z），各4张。
    - 三元牌：白（5z）、发（6z）、中（7z），各4张。

### 1.3 牌型构成规则
- **面子（Mentsu）**：由三张牌组成的组合，包括：
  - **顺子（Shuntsu）**：同一花色、连续数字的三张（例：456万）。
  - **刻子（Koutsu）**：三张完全相同的牌（例：中中中）。
- **对子（Jantou）**：两张完全相同的牌，用作“雀头”。
- **和牌基本型**：4组面子 + 1组对子（共14张）。部分特殊役种（如七对子、国士无双）除外。

## 2. 游戏流程与回合行动

### 2.1 局（Kyoku）与庄家（Dealer）
- 一局游戏由**东场**和**南场**组成（共8局），每局有庄家（亲）和闲家（子）。
- 庄家胡牌或流局听牌可连庄，否则轮换。

### 2.2 配牌与摸打
- **配牌**：每人13张（庄家14张，先出牌）。
- **摸牌（Deal）**：从牌山摸取一张。
- **打牌（Discard）**：从手牌选一张打出，放入河底（牌河）。
- **回合循环**：按逆时针顺序轮流摸打，直至有人和牌或流局。

### 2.3 鸣牌（Naki）—— 副露操作
- **吃（Chi）**：取上家打出的牌，与手牌组成顺子（必须立刻声明）。
- **碰（Pon）**：取任意一家打出的牌，与手牌组成刻子。
- **明杠（Min Kan）**：取任意一家打出的牌，与自己手牌中的三张相同牌组成杠。
- **暗杠（An Kan）**：自己手中有四张相同牌，宣布杠牌（不依赖他人打出）。
- **加杠（Kakan）**：在碰牌后，若手中摸到第四张相同牌，可升级为杠。
- **鸣牌后的影响**：
  - 副露后手牌不再是“门清”状态，部分役种失效（如立直、一杯口等）。
  - 杠牌会翻开“宝牌指示牌”，并增加宝牌数量。

### 2.4 立直（Riichi）
- 条件：
  - 门清（无副露）状态。
  - 听牌（差一张就和牌）。
  - 打出“宣言牌”时，支付1000点作为立直棒。
- 立直后：
  - 不能再换手牌，只能摸打（摸到的牌必须打出一张）。
  - 若胡牌，可额外获得“里宝牌”机会。
  - 放炮给立直者，支付更高点数。

### 2.5 和牌（Agari）条件
- **自摸（Tsumo）**：自己摸到听牌的最后一张。
- **荣和（Ron）**：别人打出你听牌的最后一张。
- **振听（Furiten）**：
  - 若你听牌，但之前曾打出过你当前听牌中的任何一张，则不能荣和（只能自摸）。
  - 若你立直后，别人打出你听牌牌，但你没胡，则进入“立直振听”，同样不能荣和。

### 2.6 流局（Ryukyoku）
- **荒牌流局**：牌山摸完无人胡牌。
  - 若庄家听牌则连庄，否则轮换。
- **四风连打**：开局四人连续打出同一风牌。
- **四杠散了**：牌局中出现第四个杠（不计暗杠）时流局。
- **九种九牌**：第一巡摸牌后，手牌有9种以上幺九牌，可宣告流局（可放弃）。

## 3. 役种（Yaku）与番数（Han）

### 3.1 一番役（1 Han）
- **立直（Riichi）**：门清听牌宣言。
- **一发（Ippatsu）**：立直后一巡内和牌（无鸣牌）。
- **门清自摸（Menzen Tsumo）**：门清状态下自摸。
- **平和（Pinfu）**：全部顺子，雀头非役牌，听牌两面。
- **断幺九（Tanyao）**：手牌无幺九牌（1、9、字牌）。
- **一杯口（Iipeikou）**：同一花色有两组相同的顺子（门清限定）。
- **役牌（Yakuhai）**：场风、自风或三元牌的刻子。
- **海底摸月（Haitei Raoyue）**：自摸最后一张牌和牌。
- **河底捞鱼（Houtei Raoyui）**：荣和最后一张打出的牌。

### 3.2 二番役（2 Han）
- **双立直（Double Riichi）**：第一巡未鸣牌即立直。
- **三色同刻（Sanshoku Doukou）**：三组花色相同的刻子。
- **三色同顺（Sanshoku Doujun）**：三组花色相同的顺子（非门清减一番）。
- **一气通贯（Ikkitsuukan）**：同一花色含123、456、789三组顺子。
- **对对胡（Toitoi）**：全部为刻子/杠子（无顺子）。
- **三暗刻（San Ankou）**：三个暗刻（含暗杠）。
- **混老头（Honroutou）**：全部为幺九牌（含字牌和数牌幺九）。
- **小三元（Shousangen）**：含有三元牌中的两种刻子，第三种为雀头。

### 3.3 三番役（3 Han）
- **混一色（Honitsu）**：手牌仅由一种花色 + 字牌构成。
- **纯全带幺（Junchan）**：所有面子/雀头都含幺九数牌（无字牌）。

### 3.4 六番役（6 Han）
- **清一色（Chinitsu）**：手牌仅由一种花色构成（无字牌）。

### 3.5 满贯（Mangan）以上（特殊役种）
- **天和（Tenhou）**：庄家配牌直接和牌。
- **地和（Chiihou）**：闲家第一巡摸牌自摸（无人鸣牌）。
- **大三元（Daisangen）**：三种三元牌均为刻子。
- **四暗刻（Suuankou）**：全部为暗刻（含暗杠），单骑听牌时四暗刻单骑为役满。
- **国士无双（Kokushi Musou）**：十三种幺九牌各一张 + 任一张重复。
- **九莲宝灯（Chuuren Poutou）**：万/筒/索任意一种花色，1112345678999 + 任一相同牌。
- **小四喜（Shousuushii）**：三种风牌为刻子，第四种为雀头。
- **大四喜（Daisuushii）**：四种风牌均为刻子。
- **字一色（Tsuuiisou）**：全部由字牌组成。
- **清老头（Ryuuiisou）**：全部由幺九数牌组成（即19万19筒19索）。
- **绿一色（Ryuuiisou）**：全部为绿色牌（索子2,3,4,6,8 + 发）。
- **四杠子（Suukantsu）**：本局出现四个杠（含明暗杠，且杠牌者和牌）。

## 4. 点数计算基础

### 4.1 符数（Fu）
- 根据手牌组成计算底符（通常20符起），加上额外符（刻子/杠子的符、听牌方式符、雀头符等）。
- 和牌方式（自摸/荣和）不直接决定符，但影响最终点数。

### 4.2 番数与点数关系
- 点数 = 基本点 × 2^(番数+2) ，基本点由符数决定。
- 实际支付：亲（庄家）支付约1.5倍，子（闲家）按比例分摊。
- **点数切上**：不足100点按100点计算。
- **满贯以上不再按符计算，按番数定级**：
  - 满贯（Mangan）：5番或符数≥70的4番 → 8000点（亲12000）。
  - 跳满（Haneman）：6-7番 → 12000点（亲18000）。
  - 倍满（Baiman）：8-10番 → 16000点（亲24000）。
  - 三倍满（Sanbaiman）：11-12番 → 24000点（亲36000）。
  - 役满（Yakuman）：13番以上或特殊役 → 32000点（亲48000），多个役满可叠加。

### 4.3 供托与返点
- 立直棒（1000点）由和牌者收取。
- 本场费（场棒）每局累加，和牌或流局听牌由胜者收取。

## 5. 特殊规则与限定

### 5.1 宝牌（Dora）与赤宝牌（Akadora）
- **宝牌指示牌**：杠或海底时翻出，其下一张（按数牌顺序，字牌按固定顺序）为宝牌。
- **里宝牌（Ura Dora）**：立直和牌后，额外翻开指示牌下的牌。
- **赤宝牌**：通常为5万、5筒、5索各一张，视为宝牌，可增加番数。
- 宝牌不计入役种，只增加番数。

### 5.2 头跳（Atama Hane）
- 多人同时荣和时，按逆时针顺序，排在下家的和牌者优先。

### 5.3 包牌（Pakao）规则（常见于一般规则）
- 若某家放炮给立直者，且立直者一发自摸，则放炮者需支付全部点数（部分规则）。

### 5.4 牌山剩余牌数提示
- 游戏中应始终保持对牌山剩余张数的认知（影响流局或海底判断）。

## 7. 注意事项（规则边界）

- **振听规则**严格限制荣和，但自摸不受影响。
- **立直后**必须摸牌即打，不能进行吃碰杠操作（杠牌视为摸牌后的动作，但通常不允许暗杠后改变听牌）。
- **同巡振听**：若在同一巡内有人打出你听牌牌，但你未荣和，则该巡内你不能荣和任何人的牌（仅限于该巡）。
- **九种九牌**的流局权仅在第一巡摸牌后（鸣牌前）有效。
- **四杠散了**流局条件：若同一局出现第四次杠（包括暗杠），则流局，但如果第四次杠后紧接着有人和牌，则优先和牌。
