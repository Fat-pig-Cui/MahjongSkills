# 立直麻将规则参考手册（索引）

本仓库曾将各章节内容汇总在本文件。为避免汇总副本与正文在雀魂平台差异、版本更新和裁定细节上产生矛盾，现以各主题 SKILL 和规则基线作为唯一维护入口。

## 阅读顺序

1. [规则基线与来源](rules-sources.md)：确认本仓库采用的雀魂四人麻将段位场规则与平台差异。
2. [根目录 SKILL](../SKILL.md)：按主题进入基础、流程、役种、计分、赛制和特殊裁定。
3. [和牌牌例](example-hands.md)、[计分实例](example-scoring.md)、[流程示例](example-gameplay.md)：用于复核具体规则。

## 维护约定

- 默认讨论雀魂四人麻将段位场；三麻、比赛房和其他平台必须显式标注。
- 规则变更时先更新本目录的 [rules-sources.md](rules-sources.md)，再修改相应主题章节与示例。
- 不在本文件重新复制规则正文，避免出现过期的头跳、包牌、四杠散了或算分说明。
