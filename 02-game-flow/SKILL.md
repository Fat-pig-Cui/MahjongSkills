# 2. 游戏流程与回合行动

## 2.1 局（Kyoku）与庄家（Dealer）

- 一盘游戏由**东场**和**南场**组成，每局有庄家（亲）和闲家（子）。
- 庄家胡牌或流局听牌可连庄，否则轮换。

## 2.2 配牌与摸打

- **配牌**：每人13张（庄家14张，先出牌）。
- **摸牌（Deal）**：从牌山摸取一张。
- **打牌（Discard）**：从手牌选一张打出，放入河底（牌河）。
- **回合循环**：按逆时针顺序轮流摸打，直至有人和牌或流局。

## 2.3 鸣牌（Naki）—— 副露操作

| 操作              | 说明                  |
|-----------------|---------------------|
| **吃（Chi）**      | 取上家打出的牌，与手牌组成顺子     |
| **碰（Pon）**      | 取任意一家打出的牌，与手牌组成刻子   |
| **明杠（Min Kan）** | 取任意一家打出的牌，加三张相同牌组成杠 |
| **暗杠（An Kan）**  | 手中有四张相同牌时宣布杠牌       |
| **加杠（Kakan）**   | 碰牌后摸到第四张相同牌，升级为杠    |

鸣牌后手牌不再是"门清"状态，部分役种失效（如立直、一杯口等）。
杠牌会翻开"宝牌指示牌"，增加宝牌数量。

## 2.4 立直（Riichi）

- **条件**：门清状态 + 听牌 + 支付1000点立直棒。
- **立直后**：不能再换手牌，只能摸打；胡牌可额外获得"里宝牌"机会。

## 2.5 和牌（Agari）条件

- **自摸（Tsumo）**：自己摸到听牌的最后一张。
- **荣和（Ron）**：别人打出你听牌的最后一张。
- **振听（Furiten）**：
  - 曾打出过当前听牌中的任意一张 → 不能荣和，只能自摸。
  - 立直后放过他人打出的听牌 → "立直振听"，同样不能荣和。

## 2.6 流局（Ryukyoku）

| 类型   | 说明                       |
|------|--------------------------|
| 荒牌流局 | 牌山摸完无人胡牌                 |
| 四风连打 | 开局四人连续打出同一风牌             |
| 四杠散了 | 出现第四个杠（不计暗杠）时流局          |
| 九种九牌 | 第一巡手牌有9种以上幺九牌，可宣告流局（可放弃） |
