# 2. 游戏流程与回合行动

> 默认适用雀魂四人麻将段位场。终局与排名见 [段位赛赛制](../08-match-rules/SKILL.md)，鸣牌和杠的完整时序见 [鸣牌与杠](../09-call-kan-rules/SKILL.md)。

## 2.1 座次、场、局、庄家与本场

- 四名玩家以东、南、西、北为起家，行动顺序逆时针；自己的上家在顺时针方向，下家在逆时针方向。
- 一局只有一名庄家（亲），其余为闲家（子）。东1局由东家坐庄；庄家轮换时交给下家。
- 庄家和牌、荒牌流局时庄家听牌、或途中流局，庄家连庄，局号不变；其余情况庄家轮换。
- 本场从0本开始。庄家连庄, 荒牌流局, 途中流局后本场加1；其他情况(只有闲家和牌)本场归0。

## 2.2 开局与摸打循环

1. 每名闲家配13张，庄家配14张并先打出一张(根据手牌也可以暗杠或天和)。
2. 之后依次从牌山摸一张、打出一张，打出的牌组成牌河。
3. 其他玩家可以在该舍牌后按规则荣和、碰、杠；只有下家可以吃。无人鸣牌时轮到下家摸牌。
4. 循环至有人和牌、途中流局，荒牌流局(牌山摸尽)。

## 2.3 听牌、立直与立直棒

- **听牌**是只需一张牌即可构成和牌型的状态；听牌只判断牌型结构，不判断是否有役。
- **可和牌**除构成和牌型外，还必须至少具备一个役；宝牌不能单独充当役。因此，无役听牌可以继续改良手牌，但在有役之前无法和牌。
- **立直条件**：门清、听牌、点数不少于1000点，且在自己的舍牌时支付1000点立直棒。
- 立直后手牌原则上固定，只能摸切；仅在满足听牌形不变等条件时可暗杠。不能吃、碰或加杠。
- 立直成立后可获得立直役；若在下一次自己摸牌前和牌且期间没有任何鸣牌或杠打断，可获得一发；立直和牌时可翻里宝牌。
- 立直棒放入供托。和牌时由和牌者取得；流局时保留。无人和牌而终局时的归属见 [段位赛赛制](../08-match-rules/SKILL.md)。

## 2.4 和牌与振听

- **自摸**：在自己摸牌或岭上摸牌时和牌；自摸点数由其余三家支付。
- **荣和**：对手舍出和牌张时宣告和牌；通常由放铳者支付全部点数。
- **舍张振听**：自己的牌河中存在当前任何一种荣和牌时，不能荣和；改变听牌形可解除。
- **同巡振听**：非立直者放过可荣和牌后，在下一次自己舍牌前不能荣和；自摸不受影响。
- **立直后振听**：立直后放过可荣和牌，或因振听而无法荣和时，直至本局结束不能荣和；仍可自摸。

## 2.5 和牌后的结算与局数推进

1. 按 [役种](../03-yaku-han/SKILL.md) 确认役、番与役满，再按 [计分](../04-scoring/SKILL.md) 计算符、基础点、支付、本场和供托。
2. 庄家和牌则连庄并增加一本；闲家和牌则庄家轮换、本场归0。
3. 多人荣和、责任支付等平台规则差异，按 [规则基线](../reference/rules-sources.md) 处理。

## 2.6 荒牌流局与途中流局

### 荒牌流局

通常牌山摸尽而无人和牌时荒牌流局。

- 听牌者与未听牌者之间结算合计3000点的听牌罚符；具体分配见 [计分](../04-scoring/SKILL.md)。
- 庄家听牌则连庄；未听牌则轮庄。
- 无论庄家是否听牌，本场加1，立直棒留在供托。

### 途中流局

以下均不进行荒牌罚符，本场加1且庄家连庄：

| 类型   | 条件                                   |
|------|--------------------------------------|
| 九种九牌 | 未发生鸣牌时，第一巡自己摸牌后手中有九种或以上不同的幺九牌；可选择不宣告 |
| 四风连打 | 四名玩家第一张舍牌均为同一种风牌，且期间无人鸣牌             |
| 四家立直 | 四名玩家均成功立直                            |
| 四杠散了 | 第四个杠成立后触发；同一玩家完成四杠子并可继续和牌时为例外        |

途中流局与抢杠、岭上开花等优先关系见 [规则边界](../07-edge-cases/SKILL.md)。
