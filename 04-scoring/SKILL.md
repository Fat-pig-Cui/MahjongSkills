# 4. 点数计算基础

## 4.1 符数（Fu）

- 根据手牌组成计算底符（通常20符起），加上额外符：
  - 刻子/杠子的符
  - 听牌方式符
  - 雀头符
- 和牌方式（自摸/荣和）不直接决定符，但影响最终点数。

## 4.2 番数与点数关系

- 点数 = 基本点 × 2^(番数+2)，基本点由符数决定。
- 实际支付：亲（庄家）支付约1.5倍，子（闲家）按比例分摊。
- **点数切上**：不足100点按100点计算。

### 满贯以上定级表

| 级别 | 番数条件 | 点数（子/亲） |
|------|----------|---------------|
| 满贯（Mangan） | 5番 或 符数≥70的4番 | 8000 / 12000 |
| 跳满（Haneman） | 6-7番 | 12000 / 18000 |
| 倍满（Baiman） | 8-10番 | 16000 / 24000 |
| 三倍满（Sanbaiman） | 11-12番 | 24000 / 36000 |
| 役满（Yakuman） | 13番以上或特殊役 | 32000 / 48000 |

多个役满可叠加（如双倍役满 = 64000点）。

## 4.3 供托与返点

- **立直棒**（1000点）：由和牌者收取。
- **本场费（场棒）**：每局累加，和牌或流局听牌由胜者收取。
