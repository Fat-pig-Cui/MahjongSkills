# 4. 点数计算

> 默认适用雀魂四人麻将段位场。先确认 [役种](../03-yaku-han/SKILL.md)，再计算符与番，最后计算支付。

## 4.1 计算顺序

1. 确认和牌形、役、宝牌与总番数。
2. 计算符，向上取整至10符。
3. 计算基本点：`符 × 2^(番数 + 2)`；达到满贯时按满贯截断。
4. 按亲/子、荣和/自摸换算支付，并向上取整到100点。
5. 加上本场与立直棒；包牌、多家荣和按规则基线处理。

## 4.2 符数

### 基础与和牌方式

|        项目        |       符       |
|:----------------:|:-------------:|
|       基础符        |      20符      |
|       门清荣和       |     +10符      |
|        自摸        |      +2符      |
|       平和自摸       |  固定20符，不加自摸符  |
|       七对子        | 固定25符，不另计其他符  |
|  副露荣和且所有结构均不产生符  |   30符（食和加符）   |

### 雀头、面子与待牌

| 种类 | 中张牌 | 幺九牌 |
|:--:|:---:|:---:|
| 明刻 | 2符  | 4符  |
| 暗刻 | 4符  | 8符  |
| 明杠 | 8符  | 16符 |
| 暗杠 | 16符 | 32符 |

|    分类     |         符          |
|:---------:|:------------------:|
|  役牌作为雀头   | +2符；场风与自风重合可合计+4符  |
| 单骑、边张、坎张听 |        +2符         |
|  两面、双碰听   |        +0符         |

- 荣和牌若用来组成刻子，该刻子按明刻计；若荣和牌完成的是雀头，则不改变既有暗刻的性质。
- 加总后向上取整至10符。常见例外是平和自摸固定20符、七对子固定25符，以及副露荣和最低30符。

## 4.3 满贯截断与等级

| 等级  | 条件                   |  子家荣和 |  庄家荣和 |
|-----|----------------------|------:|------:|
| 满贯  | 5番，或4番达到40符，或3番达到70符 |  8000 | 12000 |
| 跳满  | 6至7番                 | 12000 | 18000 |
| 倍满  | 8至10番                | 16000 | 24000 |
| 三倍满 | 11至12番               | 24000 | 36000 |
| 役满  | 役满或累积役满              | 32000 | 48000 |

- 段位场默认不采用切上满贯：4番30符与3番60符仍使用普通公式。
- 双倍役满按两倍役满支付；多个自然役满按役满倍数累计。累积役满固定为单倍役满：即使番数达到26番或更高，也不与自然役满复合。

## 4.5 本场、立直棒与荒牌罚符

- **本场**：每本总额为`(玩家数-1)*100`点，四麻300、三麻200，n本乘n。荣和由放铳者支付；自摸由每名实际非和牌者支付每本100点。多家荣和时，本场加点只付给从放铳者开始逆时针遇到的第一位和牌者，不按和牌人数重复收取。
- **立直棒（供托）**：每根1000点；单家和牌时取得桌面全部立直棒，多家荣和时全部归上述逆时针第一位和牌者；流局不退回。
- **多家荣和**：每位和牌者仍分别按自己的符番取得和牌点数；只有本场与供托集中给同一位和牌者。判断方向按当局座次东→南→西→北→东，从放铳者的下一家起跳过未和牌者。三麻按东→南→西→东，详见 [三麻章节](../13-sanma/SKILL.md)。
- **荒牌罚符**：有人听牌且有人未听牌时，听牌者合计收`(玩家数-1)*1000`点，未听牌者合计付同额：四麻3000、三麻2000。听牌方内部、未听牌方内部各自均分；全员听牌或全员未听牌时不收付。以下为四麻表，三麻表见第13章。

| 听牌人数 | 每名听牌者获得 | 每名未听牌者支付 |
|------|--------:|---------:|
| 0或4  |       0 |        0 |
| 1    |    3000 |     1000 |
| 2    |    1500 |     1500 |
| 3    |    1000 |     3000 |
