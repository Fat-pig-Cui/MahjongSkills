# 4. 点数计算

> 默认适用雀魂四人麻将段位场。先确认 [役种](../03-yaku-han/SKILL.md)，再计算符与番，最后计算支付。

## 4.1 计算顺序

1. 确认和牌形、役、宝牌与总番数。
2. 计算符，向上取整至10符。
3. 计算基本点：`符 × 2^(番数 + 2)`；达到满贯时按满贯截断。
4. 按亲/子、荣和/自摸换算支付，并向上取整到100点。
5. 加上本场与立直棒；责任支付、多家荣和按规则基线处理。

## 4.2 符数

### 基础与和牌方式

| 项目 | 符 |
|---|---:|
| 基础符 | 20符 |
| 门清荣和 | +10符 |
| 自摸 | +2符 |
| 平和自摸 | 固定20符，不加自摸符 |
| 七对子 | 固定25符，不另计其他符 |
| 副露荣和且所有结构均不产生符 | 30符（食和加符） |

### 雀头、面子与待牌

| 项目 | 简单牌 | 幺九牌或字牌 |
|---|---:|---:|
| 暗刻 | 4符 | 8符 |
| 明刻 | 2符 | 4符 |
| 暗杠 | 16符 | 32符 |
| 明杠 | 8符 | 16符 |

| 项目 | 符 |
|---|---:|
| 场风、自风、白、发、中作为雀头 | 各+2符；场风与自风重合可合计+4符 |
| 单骑、边张、嵌张听 | +2符 |
| 两面、双碰、对倒听 | +0符 |

- 荣和得到的刻子，除非是单骑和牌造成的既有暗刻，一般按明刻计。
- 加总后向上取整至10符。常见例外是平和自摸固定20符、七对子固定25符，以及副露荣和最低30符。

## 4.3 满贯截断与等级

| 等级 | 条件 | 子家荣和 | 庄家荣和 |
|---|---|---:|---:|
| 满贯 | 5番，或4番40符以上，或3番70符以上 | 8000 | 12000 |
| 跳满 | 6至7番 | 12000 | 18000 |
| 倍满 | 8至10番 | 16000 | 24000 |
| 三倍满 | 11至12番 | 24000 | 36000 |
| 役满 | 役满或数え役满 | 32000 | 48000 |

- 段位场默认不采用切上满贯：4番30符与3番60符仍使用普通公式。
- 多倍役满的支付按役满倍数相乘；数え役满、双倍役满与累计方式见 [规则基线](../reference/rules-sources.md)。

## 4.5 本场、立直棒与荒牌罚符

- **本场**：荣和时放铳者每本额外支付300点；自摸时每名非和牌者每本额外支付100点。
- **立直棒**：每根1000点，和牌者一次取得桌面全部立直棒；流局不退回。
- **荒牌罚符**：听牌者合计收3000点，未听牌者合计付3000点。

| 听牌人数 | 每名听牌者获得 | 每名未听牌者支付 |
|---|---:|---:|
| 0或4 | 0 | 0 |
| 1 | 3000 | 1000 |
| 2 | 1500 | 1500 |
| 3 | 1000 | 3000 |
